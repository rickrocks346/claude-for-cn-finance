# 投资组合风险指标计算

> 本 skill 计算投资组合的核心风险指标。用户提供组合持仓和权重后，自动计算并解读各项指标。
> 只做描述性分析，不提供调仓建议。

## 概述

对用户提供的投资组合进行系统性的风险指标计算，覆盖波动率、回撤、夏普比率、VaR、相关性等维度。提供每个指标的公式、计算方法和中国市场的参考区间。

## 核心风险指标体系

### 1. 波动率（年化）
```
日收益率: r_t = (NAV_t - NAV_{t-1}) / NAV_{t-1}
年化波动率 = std(r_t) × √252
```
| 组合类型 | 中国 A 股典型波动率 | 成熟市场参考 |
|---------|------------------|------------|
| 纯股票型 | 18-30% | 12-20% |
| 混合型（股债各半） | 8-15% | 6-12% |
| 偏债混合型 | 3-8% | 2-5% |
| 纯债券型 | 1-5% | 1-4% |
| 货币型 | < 1% | < 0.5% |

> 中国 A 股波动率显著高于成熟市场，主要原因是散户占比高、政策驱动性强、市场深度不足。

### 2. 最大回撤 (Maximum Drawdown)
```
MDD = max_{t > s} (P_t - P_s) / P_s  （取最小值，即最大亏损）
其中 P_t 为时点 t 的组合净值
```
| 组合类型 | 中国 A 股典型最大回撤 |
|---------|-------------------|
| 纯股票型 | 25-50% |
| 混合型（股债各半） | 15-30% |
| 偏债混合型 | 5-15% |
| 纯债券型 | 1-5%（信用债可能 5-10%） |

附加指标：
- **回撤持续天数**：从峰值到谷值的交易日数
- **回撤恢复天数**：从谷值回到前高所需交易日数（越长说明越脆弱）
- **回撤频率**：回撤超过 5%/10%/20% 的次数/年

### 3. 夏普比率 (Sharpe Ratio)
```
夏普比率 = (R_p - R_f) / σ_p
其中：R_p = 组合年化收益率, R_f = 无风险利率, σ_p = 年化波动率
```
| 夏普比率 | 评价 |
|---------|------|
| < 0 | 跑输无风险利率 |
| 0-0.5 | 偏低 |
| 0.5-1.0 | 中等（A 股多数基金在此区间） |
| 1.0-1.5 | 良好 |
| 1.5-2.0 | 优秀 |
| > 2.0 | 极优秀（注意检查是否有幸存者偏差或数据过短） |

中国市场无风险利率 R_f 建议取 10 年期国债收益率（约 2.5-3.5%），而非 1 年期定存。

### 4. 索提诺比率 (Sortino Ratio)
```
索提诺比率 = (R_p - R_f) / σ_down
其中 σ_down = 下行波动率（仅计算负收益的标准差）
```
- 比夏普比率更合理：上行波动是"好的波动"，不应被惩罚
- 索提诺比率 > 夏普比率 → 组合收益正偏（涨多跌少）
- 索提诺比率 < 夏普比率 → 组合收益负偏（跌多涨少，更需关注）

### 5. VaR（在险价值）

#### 历史模拟法（推荐，最直观）
```
VaR(95%, 1天) = 历史日收益率从低到高排列的第 5 百分位数 × 组合价值
VaR(95%, 1月) = VaR(95%, 1天) × √21
```

#### 参数法（假设正态分布）
```
VaR(95%, 1天) = (μ - 1.645 × σ) × 组合价值
```
> 中国 A 股收益率分布呈肥尾和负偏特征，参数法会低估极端风险。

#### 蒙特卡洛法
对复杂组合（含衍生品、非标资产等），用模拟路径计算 VaR。

| VaR 水平 | 含义 |
|---------|------|
| VaR(95%, 1天) = -2% | 在 95% 的交易日里，单日亏损不超过 2% |
| VaR(99%, 1月) = -10% | 在 99% 的月份里，月度亏损不超过 10% |

### 6. CVaR（Expected Shortfall / 条件在险价值）
```
CVaR(95%) = E[亏损 | 亏损 > VaR(95%)]
        = 最差的 5% 日收益的平均值
```
| VaR vs CVaR | VaR(95%) | CVaR(95%) |
|-------------|----------|-----------|
| 含义 | 第 5 百分位的亏损 | 超过 VaR 的那 5% 的平均亏损 |
| 优点 | 简单直观 | 捕捉尾部风险 |
| 缺点 | 不知道超出 VaR 后亏多少 | 对极端值敏感 |

> 中国 A 股的 CVaR 通常比 VaR 严重得多（肥尾特征明显）。

### 7. Beta（系统性风险）
```
β = Cov(R_portfolio, R_benchmark) / Var(R_benchmark)
```
- 一般以沪深 300（大盘基准）或中证全指（全市场基准）为参照
- |β| 判断：
  - β > 1.2 → 高 Beta（牛市涨更多、熊市跌更多）
  - 0.8 < β < 1.2 → 市场中性
  - β < 0.8 → 低 Beta（防御型组合）
  - β < 0 → 反向相关（对冲型/做空型，中国极少）

### 8. 相关性矩阵
- 持仓之间的 Pearson 相关系数（日/周频）
- 组合整体与各基准的相关性
- **平均相关性** = 所有持仓两两相关的均值——越低分散效果越好
- 中国 A 股内部相关性较高（同涨同跌严重），国际分散化更有价值

### 9. 额外指标
| 指标 | 公式 | 用途 |
|------|------|------|
| 卡玛比率 (Calmar) | 年化收益 / 最大回撤 | 回撤调整后的收益效率 |
| 信息比率 (IR) | (R_p - R_benchmark) / σ(R_p - R_benchmark) | 超额收益稳定性 |
| 跟踪误差 (TE) | σ(R_p - R_benchmark) | 相对基准的偏离度 |
| Omega 比率 | Σmax(r_i - τ, 0) / Σmax(τ - r_i, 0) | 考虑全部分布的收益/亏损比 |
| 偏度 (Skewness) | E[(r - μ)³] / σ³ | 负偏 = 极端亏损频率高 |
| 峰度 (Kurtosis) | E[(r - μ)⁴] / σ⁴ | > 3 = 肥尾——极端事件比正态分布多 |

## 风险归因

### 绝对风险归因
```
组合总风险(σ²_p) = Σ w_i² σ²_i + Σ Σ w_i w_j σ_i σ_j ρ_ij
                = 个体风险贡献 + 协方差风险贡献
```
- 个体风险：如果某持仓权重高且自身波动大
- 协方差风险：如果某持仓与其他持仓相关性高

### 边际风险贡献 (MRC)
```
MRC_i = ∂σ_p / ∂w_i = (w_i σ²_i + Σ_{j≠i} w_j σ_i σ_j ρ_ij) / σ_p
```
- MRC_i × w_i = 持仓 i 对组合总风险的贡献百分比
- 风险贡献最大的持仓不一定是权重最大的持仓

## A 股特有风险因素

| 因素 | 说明 | 影响 |
|------|------|------|
| 政策风险溢价 | 中国政策对市场的驱动性强于成熟市场 | 波动率中枢偏高 |
| T+1 和涨跌停限制 | 流动性受限时的风险被压缩后集中释放 | 跌停板连续出现时 VaR 模型失效 |
| 注册制 IPO 供给 | 小市值公司供给增加 | 小盘股估值中枢下移 |
| 外资流动（北向资金） | 日度净买卖影响边际定价 | 外资重仓股波动加大 |
| 中概/港股联动 | 通过港股通+ADR 传导 | 增加了跨境风险暴露 |

## 分析流程

1. 用户提供组合持仓和权重（或上传 Excel/CSV）
2. 获取各持仓的历史价格数据（建议 ≥ 3 年日频数据）
3. 计算组合日收益率序列（权重 × 各持仓收益率求和）
4. 逐一计算风险指标
5. 计算风险归因（各持仓对总风险的贡献）
6. 将各指标与同类型组合的参考区间对比
7. 识别异常值或突出的风险特征
8. 输出风险指标一览表
