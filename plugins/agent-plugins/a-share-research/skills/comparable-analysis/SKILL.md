# A股可比公司分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取行情和财务数据。

## 概述

基于申万/中信行业分类体系，在中国 A 股市场筛选可比公司，进行多维度的估值与经营指标对比。

## 可比公司选取方法

### 筛选流程（分层漏斗）
```
第1层：申万三级/四级行业 → 剔除 ST/*ST/退市 → 剔除上市 < 1年
第2层：市值 0.3x-3x 目标公司 → 主营业务相似度过滤
第3层：如剩余 < 5 家 → 放宽至申万二级行业 → 仍不足 → 全行业分位
```

### 业务相似度评估维度
| 维度 | 评分标准 | 权重 |
|------|---------|------|
| 主营产品/服务一致性 | 主营构成重叠度（按收入占比加权） | 40% |
| 商业模式相似度 | B2B/B2C/B2G、直销/经销、轻/重资产 | 25% |
| 客户/市场地域重合度 | 国内/海外收入比例 | 15% |
| 产业链位置 | 上游/中游/下游/平台 | 10% |
| 收入规模数量级 | 同一数量级（10 亿/100 亿/1000 亿） | 10% |

总分 > 0.7 视为可比，0.5-0.7 视为弱可比（标注），< 0.5 排除。

### A股特殊筛选条件
| 条件 | 原因 |
|------|------|
| 排除 ST / *ST / 退市整理期 | 非正常经营状态，估值失真 |
| 排除上市 < 1 年 | 新股效应（估值溢价+业绩变脸风险） |
| 排除停牌 > 3 个月 | 价格不连续，历史分位失真 |
| 排除重大资产重组后 < 1 年 | 主业已发生变化 |
| 排除一致行动人合计持股 > 90% | 流动性不足，价格信号失真 |

### 选取数量
- 理想区间：5-15 家
- 3-4 家：勉强可分析但统计不稳健，需额外标注
- < 3 家：无法做分位统计，改用全行业估值分位法

## A股常用估值倍数（完整版）

### PE 系列
| 变体 | 计算 | 适用场景 | A股注意事项 |
|------|------|---------|-----------|
| PE (TTM) | 市值 / 近4个季度归母净利润 | 通用 | 最常用，但净利润含非经常性 |
| PE (扣非 TTM) | 市值 / 近4个季度扣非净利润 | 盈利质量分析 | 更反映主营业务，A股推荐首选 |
| PE (Forward) | 市值 / 未来12个月一致预期EPS | 前瞻估值 | 需一致预期数据，小市值公司覆盖不足 |
| PE (静态) | 市值 / 上年度归母净利润 | 历史比较 | 时效性差，较少使用 |

### 其他常用倍数
| 倍数 | 计算 | 适用行业 | A股注意事项 |
|------|------|---------|-----------|
| PB | 市值 / 归属母公司净资产 | 金融、周期、重资产 | 注意商誉和无形资产对净资产的扭曲 |
| PS (TTM) | 市值 / 近12个月营收 | 成长型/亏损公司 | 收入确认政策影响可比性（总额法 vs 净额法） |
| EV-EBITDA | (市值+净债务+少数股东权益) / EBITDA | 制造业、重资产 | 排除资本结构和折旧政策差异 |
| PEG | PE / 净利润增速(%) | 成长股 | 增速取未来 1-3 年复合增速更合理 |
| PCF | 市值 / 经营活动现金流净额 | 现金流型公司 | 比 PE 更难操纵 |
| P/FCFE | 市值 / 股权自由现金流 | 成熟公司 | 扣除维持性 CAPEX 后的现金流 |

### 分行业估值倍数选择指南
| 申万一级 | 首选 | 次选 | 参考 | 不适用 | 原因 |
|---------|------|------|------|--------|------|
| 银行 | PB | PE | P/PPOP | EV-EBITDA | 高杠杆经营 |
| 非银-券商 | PB | PE | P/BV | EV-EBITDA | 强周期+高杠杆 |
| 非银-保险 | P/EV | PB | PE | — | 内含价值是保险核心 |
| 食品饮料 | PE(扣非) | PEG | EV-EBITDA | PB | 稳定盈利，品牌溢价 |
| 医药生物 | PE(扣非) | PEG | PS(亏损期) | PB | 研发开支扭曲净资产 |
| 电子 | PE | EV-EBITDA | PS | PB | CAPEX 大，折旧影响 |
| 计算机 | PS | PE | EV/Revenue | PB | 轻资产，利润波动大 |
| 电力设备 | PE | PEG | EV-EBITDA | PB | 高增长+CAPEX 大 |
| 房地产 | PB(NAV) | PE | P/RNAV | EV-EBITDA | 资产价值是核心 |
| 建筑装饰 | PE | PB | EV-EBITDA | — | 订单驱动，应收风险大 |
| 汽车 | PE | EV-EBITDA | PS | PB | CAPEX 大，周期波动 |
| 公用事业 | PE | PB | 分红率 | EV-EBITDA | 现金流稳定，分红重要 |
| 化工 | PE | EV-EBITDA | PB | — | 周期性强，底部看 PB |
| 煤炭 | PE | EV-EBITDA | 分红率 | — | 盈利跟随煤价强周期 |
| 通信 | PE | EV-EBITDA | PS | PB | 运营商与设备商逻辑不同 |

## 历史分位数分析

### 数据范围建议
| 场景 | 建议历史区间 | 原因 |
|------|------------|------|
| 正常市场 | 5 年 | 覆盖一个政策周期+一个库存周期 |
| 快速成长行业 | 3 年 | 5 年前公司体量和行业格局已完全不同 |
| 强周期行业 | 7-10 年 | 需要覆盖完整周期高低点 |
| 新股/次新股 | 仅可用期间 | 明确标注数据期间限制 |

### 分位数解读框架
| 分位 | 含义 | 典型估值情景 |
|------|------|------------|
| < 10% | 接近历史底部 | 极度悲观、危机时期 |
| 10-25% | 历史低位 | 行业低谷、市场系统性下跌 |
| 25-40% | 历史中低位 | 偏便宜，可能有机会 |
| 40-60% | 历史中位 | 合理估值区间 |
| 60-80% | 历史中高位 | 偏贵，市场情绪乐观 |
| 80-90% | 历史高位 | 明显偏贵，需强基本面支撑 |
| > 90% | 接近历史顶部 | 泡沫区域，风险收益比差 |

### 分位使用注意事项
- **均值回归陷阱**：公司基本面发生永久性变化时（如行业逻辑颠覆），历史分位失去参考意义
- **IPO 锚定效应**：A股次新股的历史估值区间过短，分位统计不稳定
- **结构性变化**：注册制改革后小市值公司估值中枢可能永久性下移

## A股估值溢价/折价分析

### 如何量化估值溢价
```
估值溢价(%) = (目标 PE - 可比组中位数 PE) / 可比组中位数 PE × 100%
```

### 合理溢价的可能来源
| 溢价来源 | 量化标志 | 合理溢价范围 |
|---------|---------|------------|
| 成长性溢价 | 收入/利润增速连续3年 > 行业中位数 | 10-30% |
| 质量溢价 | ROE > 行业中位数 5pp+、经营现金流/净利润 > 1 | 10-20% |
| 龙头溢价 | 市值行业前3、市占率 > 20% | 10-30% |
| 品牌溢价 | 毛利率 > 行业中位数 10pp+ | 5-15% |
| 治理溢价 | 机构持股 > 50%、分红稳定 | 5-10% |

### A股特殊折价因素
| 折价来源 | 量化标志 | 典型折价 |
|---------|---------|---------|
| 股权质押比例过高 | 控股股东质押 > 80% | 10-20% |
| 关联交易占比过高 | 关联交易/收入 > 30% | 10-20% |
| 审计意见非标 | 带强调事项段无保留/保留意见 | 20-40% |
| 行业政策不确定性 | 集采/监管等悬而未决 | 10-30% |
| 国企折价（部分行业） | 国企且管理层激励不足 | 5-15% |

## 可比组异常值处理

### 识别方法
- 任一估值倍数 > 可比组中位数 ± 3×MAD（中位数绝对偏差）
- 标记为异常值，单独列出，不纳入中位数/均值计算

### 异常值原因分析
| 原因 | 处理 |
|------|------|
| 微利导致 PE 极高（EPS < 0.01） | 剔除 PE，改用 PS/PB |
| 亏损导致 PE 为负 | PE 不可用，改用 PS/PB/EV-EBITDA |
| 净资产为负 | PB 不可用 |
| 一次性损益扭曲 | 改用扣非口径 |

## 分析流程

1. 确定目标公司所在行业（申万三级优先）
2. 按分层漏斗筛选可比公司
3. 业务相似度评分并排序，取前 5-15 家
4. 获取估值倍数和核心财务指标（统一为 TTM 口径）
5. 异常值检测和处理
6. 计算行业中位数、25/75 分位、均值（剔除异常值）
7. 对比目标公司在可比组中的位置（当前 + 历史分位）
8. 分析溢价/折价来源
9. 输出比较报告
