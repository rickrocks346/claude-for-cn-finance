# 基金风格漂移检测

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金净值、持仓和基准数据。

## 概述

检测公募基金是否偏离其合同约定的投资风格（名称漂移、仓位漂移、市值漂移、行业漂移），帮助用户识别"名不副实"的基金。在中国市场，风格漂移是普遍现象而非孤立问题。

## 漂移类型详解

### 1. 名称/主题漂移（最直观的漂移）
基金名称暗示的投资方向与实际持仓不符：
| 典型漂移案例模式 | 示例 |
|---------------|------|
| "XX消费主题"重仓新能源 | 某消费基金持有大量宁德时代、比亚迪 |
| "XX中小盘"重仓沪深300大蓝筹 | 规模扩大后被迫大盘化（常见于明星基金） |
| "XX环保低碳"持有大量白酒/银行 | 低碳主题变成价值蓝筹 |
| "XX沪港深"不持有港股 | 港股通开通后基金范围扩大但实际不投 |

**主题纯度检测**：
```
主题关联度 = 持仓中属于主题行业(申万三级)的股票权重之和 / 股票总仓位
> 80% → 高度贴合主题
60-80% → 基本贴合
40-60% → 主题漂移（关注）
< 40% → 严重漂移（"挂羊头卖狗肉"）
```

### 2. 仓位漂移（风格偏移）
| 漂移模式 | 检测方法 | 典型表现 |
|---------|---------|---------|
| 灵活配置型长期满仓 | 近 8 季度股票仓位均 > 85%（合同约定 0-95%） | 失去了灵活配置的意义，本质上变成股票型 |
| 偏股型持续低仓位 | 股票仓位持续在合同下限附近 | 基金经理看空但不愿明说，或管理能力不足 |
| 股债比例大幅摆动 | 季度间股票仓位波动 > 30pp | 积极择时风格（少数能做到，多数是噪音交易） |
| 持有超出合同范围资产 | 出现合同未约定的资产类别 | 如纯债基金持有可转债/股票 |

### 3. 市值风格漂移
| 检测维度 | 正常波动 | 漂移信号 |
|---------|---------|---------|
| 持仓市值中位数 | 在同类区间±20%波动 | 从"小盘"跳到"大盘"区间（跨越 2 级） |
| 风格九宫格位置 | 相邻格移动 | 跨越 2 格以上（如大盘价值→小盘成长） |
| 中证 500/沪深 300 权重比 | 比例在 0.5-2 之间正常波动 | 比例从 0.5 升至 3.0（小盘化）或反之 |

**市值漂移常见原因**：
- 规模快速扩大 → 被迫从中小盘转向大盘（策略容量约束）
- 市场风格轮动 → 基金经理主动调整（可能是能力也可能是追涨）
- 小盘股流动性恶化 → 被迫减持（风控驱动）

### 4. 行业漂移
| 检测维度 | 正常波动 | 漂移信号 |
|---------|---------|---------|
| 前 3 大行业集中度 | ±10pp | 突然 > 60%（行业赌注） |
| 单一行业权重 | 0-25% | 连续 2 季 > 30%（非主题基金） |
| 行业配置与基准偏离 | 跟踪误差合理 | 行业偏离度持续 > 15% |

**行业轮动频率判断**：
```
季均行业换手 = 各行业权重变化的绝对值之和 / 2
< 10% → 行业配置稳定（买入并持有行业配置）
10-30% → 适度调整
> 30% → 高频行业轮动（小心——极少数人能持续做对）
```

### 5. 基准漂移
| 漂移模式 | 检测 |
|---------|------|
| 港股持仓 > 20% 但基准是纯 A 股 | 实际风险暴露远超基准 |
| 持有大量可转债但基准为纯债 | 风险收益特征与基准不匹配 |
| 小盘股持仓 > 50% 但基准是沪深 300 | 基准选择错误或故意"降维" |

## 风格漂移检测方法

### 方法一：持仓分析法（直接，最准确）
```
Step 1: 逐季获取前十大重仓股（季报）+ 完整持仓（年报/中报）
Step 2: 对每季度计算：市值中位数、加权 PE/PB/ROE、行业分布
Step 3: 绘制风格变动轨迹图（时间 × 风格维度）
Step 4: 计算风格指标的标准差和最大变动幅度
Step 5: 与基金合同/招募说明书中的投资范围对比
Step 6: 生成风格一致性评分
```

### 方法二：净值回归法（间接，适用持仓不可得时）
```
对 8 个风格指数做约束回归（仅做多）：
R_fund = α + w1×大盘价值 + w2×大盘成长 + w3×中盘价值 + w4×中盘成长
              + w5×小盘价值 + w6×小盘成长 + w7×债券 + w8×货币 + ε
约束: Σw = 1, w_i ≥ 0

滚动 36 个月窗口，每月做一次 → 得到风格暴露时间序列
```

中国适用风格指数：
| 风格 | A 股代理指数 |
|------|-----------|
| 大盘价值 | 中证 100 价值 / 300 价值 |
| 大盘成长 | 中证 100 成长 / 300 成长 |
| 中盘价值 | 中证 500 价值 |
| 中盘成长 | 中证 500 成长 |
| 小盘价值 | 中证 1000 价值 / 国证 2000 价值 |
| 小盘成长 | 中证 1000 成长 / 国证 2000 成长 |

### 方法三：基准偏离度法
```
跟踪误差 = std(基金日收益 - 基准日收益) × √252
> 8% → 实际组合与基准差异显著（主动管理或漂移）
> 15% → 极高偏离，基准可能完全无参考意义
```

### 方法四：同类排名分布法
- 如果基金在"成长风格"排名中表现好时自称成长，在"价值风格"排名中表现好时自称价值 → 风格不稳定
- 在同类（同风格标签）基金中的相对排名的持续性比绝对排名更重要

## 漂移严重度评级

### 风格一致性评分卡
| 维度 | 权重 | 评分方法 |
|------|------|---------|
| 主题贴合度 | 25% | 主题行业持仓占比 |
| 仓位稳定性 | 20% | 仓位波动标准差 |
| 市值风格稳定性 | 20% | 市值中位数变动 |
| 行业风格稳定性 | 15% | 行业轮动频率 |
| 基准匹配度 | 10% | 跟踪误差 |
| 因子暴露稳定性 | 10% | 因子暴露时间序列标准差 |

| 总分 | 评级 | 含义 |
|------|------|------|
| > 80 | 风格高度一致 | 投资者可以相信基金会按合同运作 |
| 60-80 | 风格基本一致 | 有轻微漂移，但大方向不变 |
| 40-60 | 风格不稳定 | 漂移明显，投资者需密切关注 |
| < 40 | 严重风格漂移 | 基金实际风格与声明几乎无关 |

## 漂移的"灰色地带"

并非所有漂移都是坏事：
| 漂移类型 | 可能是合理的情况 |
|---------|---------------|
| 市值中枢上移 | 基金规模从 5 亿→100 亿，小盘策略容量不足（被动调整） |
| 行业权重变化 | 行业基本面变化导致自然权重变化（非主动调整） |
| 风格暂时偏离 | 短期市场极端分化下的战术调整 |
| 基准扩展 | 基金经理能力圈扩展（如 A 股→含港股） |

**更应关注的是：隐瞒/误导性漂移**——调整了风格但不告知投资者。

## 分析流程

1. 获取基金合同（招募说明书）中的投资范围和风格定位
2. 获取最近 8 个季度的持仓数据（前十大）+ 最近 2 次年报/中报（完整持仓）
3. 逐季计算风格指标（市值、行业、估值、仓位）
4. 绘制风格变动轨迹
5. 与合同声明对比，量化偏离度
6. 使用净值回归法交叉验证（尤其在季报间隔期）
7. 生成风格一致性评分
8. 输出漂移检测报告
