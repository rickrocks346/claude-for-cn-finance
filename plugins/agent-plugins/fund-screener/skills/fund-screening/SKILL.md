# 基金筛选与比较

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金数据。

## 概述

基于多维度筛选条件对公募基金进行筛选和横向比较，支持股票型、混合型、债券型、货币型、QDII、ETF、FOF 等全品类。

## 中国公募基金分类体系

### 按投资类型（CSRC 官方分类）
| 类型 | 子类型 | 仓位约束 | 典型规模 |
|------|--------|---------|---------|
| 股票型 | 普通股票型、指数增强型 | 股票仓位 ≥ 80% | — |
| 混合型 | 偏股(股票60-95%)/平衡(30-60%)/偏债(0-30%)/灵活配置(0-95%) | 仓位灵活 | 中国最大品类 |
| 债券型 | 纯债(短债/中长债)、一级债(可打新)、二级债(股票≤20%)、可转债 | — | — |
| 货币型 | 场外货基、场内货基(ETF) | — | 流动性管理 |
| QDII | 股票/债券/混合/REITs/商品 | — | 海外资产配置唯一渠道 |
| ETF | 宽基/行业/主题/策略/跨境/债券/货币 | — | 场内交易+PCF机制 |
| FOF | 目标日期/目标风险/普通FOF | 基金中的基金 | 二次分散 |
| REITs | 基础设施公募REITs | — | 中国特色的基建REITs |

### 中国基金类型特殊说明
| 概念 | 说明 |
|------|------|
| LOF (上市型开放式基金) | 既可在场外申赎又可在场内交易，存在折溢价套利 |
| 分级基金 | 2020年底已全部清理转型，不再存在 |
| 保本基金 | 2019年已全部到期或转型，不再存在 |
| E-FOF vs F-LOF | FOF以场外为主，LOF形式可在场内交易 |

## 多维度筛选框架

### 1. 业绩维度
| 指标 | 计算 | 评估标准 |
|------|------|---------|
| 近 1/3/5 年累计收益率 | — | 同类排名前 1/3 为优 |
| 年化收益率 | (1+累计收益)^(1/n)-1 | > 业绩基准年化 |
| 年化波动率 | 月收益标准差 × √12 | 同类中偏低为优 |
| 夏普比率 | (年化收益 - 无风险利率) / 年化波动 | > 1 为良好，> 2 为优秀 |
| 索提诺比率 | (年化收益 - 无风险利率) / 下行波动率 | 只惩罚下行波动，更合理 |
| 最大回撤 | (峰-谷) / 峰 | < 同类中位数 |
| 回撤修复天数 | 回到前高所需天数 | 越短越好 |
| 卡玛比率 | 年化收益 / 最大回撤 | > 1 为良好 |
| 信息比率 | (基金收益 - 基准收益) / 跟踪误差 | > 0.5 说明有持续超额能力 |
| 月度胜率 | 月收益 > 基准的月数占比 | > 55% 为稳定 |

### 2. 风险维度
| 指标 | 评估 |
|------|------|
| 年化波动率（标准差） | ≤ 同类均值 |
| 最大回撤 | ≤ 同类中位数，绝对回撤需匹配用户承受力 |
| 下行标准差（只统计负收益） | ≤ 同类中位数 |
| VaR (95%) | 月度 VaR ≤ 5-8%（股票型） |
| Beta (相对沪深300) | 0.8-1.2 为正常范围 |
| 最大回撤发生时的市场环境 | 看回撤是系统性(市场跌)还是特殊性(策略失误) |

### 3. 基金规模与流动性
| 指标 | 评估 | 说明 |
|------|------|------|
| 基金总规模 | 股票型: 2-100亿较优 / 债券型: 10亿+ / 打新策略: < 10亿 | 规模是收益的敌人（尤其小盘策略） |
| 规模趋势 | 规模快速增长(>翻倍/季) → 关注策略容量 | 大量申购可能稀释 Alpha |
| 日均成交额(ETF) | > 1000 万 | 流动性充足 |
| ETF 折溢价率 | -0.5%~+0.5% 正常 | 偏离过大有套利/流动性问题 |

### 4. 基金经理维度
| 指标 | 黄灯 | 绿灯 |
|------|------|------|
| 管理本基金时长 | < 1 年 | > 3 年（覆盖完整牛熊） |
| 基金经理从业年限 | < 3 年 | > 5 年 |
| 跳槽频率 | 3 年内换 2 次以上 | 任职稳定（在同一公司 > 3 年） |
| 同时管理基金数 | > 10 只（挂名嫌疑） | 3-5 只 |
| 管理总规模 | 远超同类策略容量 | 在合理范围内 |

### 5. 费用维度
| 费用项 | 股票型 | 混合型 | 债券型 | ETF |
|--------|--------|--------|--------|-----|
| 管理费(年) | 1.2-1.5% | 1.0-1.5% | 0.3-0.8% | 0.15-0.5% |
| 托管费(年) | 0.2-0.25% | 0.2-0.25% | 0.1-0.2% | 0.05-0.1% |
| 申购费(A类) | 1.0-1.5%(折扣后0.1-0.15%) | 同 | 0.5-0.8% | 场内佣金 |
| 赎回费(<7天) | 1.5%(惩罚性) | 同 | 0.1-1.5% | 场内佣金 |
| C类销售服务费(年) | 0.4-1.0% | 0.4-1.0% | 0.2-0.4% | — |

**A 类 vs C 类选择规则**：持有 < 1 年选 C 类，持有 > 1 年选 A 类（以费用平衡点计算）

### 6. 基金公司维度
| 指标 | 说明 |
|------|------|
| 公司管理总规模 | 前 20 大通常投研体系更完善 |
| 公司同类基金平均排名 | 判断是公司 Alpha 还是个人 Alpha |
| 公司投研团队稳定性 | 频繁人员变动 → 投研体系不稳定 |
| 旗下基金风格一致性 | 同一公司同策略基金表现应该接近 |

## 特殊品类筛选要点

### 指数基金/ETF
| 指标 | 核心要求 |
|------|---------|
| 跟踪误差(年化) | < 2%（普通指基），< 1%（ETF） |
| 信息比率 | > 0（指数增强型需有正超额） |
| 规模 | ETF > 1 亿（避免清盘风险） |
| 日均成交额 | > 1000 万（避免流动性不足） |
| 折溢价 | 长期大幅溢价=套利难度大 |

### 债券基金
| 指标 | 核心要求 |
|------|---------|
| 最大回撤 | < 2%（纯债），< 5%（二级债） |
| 信用下沉程度 | 重仓 AAA 以下的占比（评级越低风险越高） |
| 久期 | 短久期(<1Y)波动小，长久期(>5Y)利率敏感 |
| 机构占比 | 单一机构 > 80% → 大额赎回风险 |

### QDII 基金
| 注意事项 |
|---------|
| 注意汇率损益（人民币贬值增厚收益，升值侵蚀收益） |
| 跟踪误差较大（时差、跨境申赎成本） |
| 额度限制可能导致暂停申购/限购 |
| 到账时间较长（赎回 T+5 到 T+10） |

## 多指标综合评分框架

### 评分权重（默认，可按用户偏好调整）
| 维度 | 股票型 | 混合型 | 债券型 |
|------|--------|--------|--------|
| 长期业绩(3/5年) | 30% | 25% | 20% |
| 风险调整收益(夏普/信息比) | 25% | 25% | 20% |
| 风险控制(回撤) | 20% | 20% | 30% |
| 基金经理稳定性 | 15% | 15% | 15% |
| 费用 | 5% | 10% | 10% |
| 规模合理性 | 5% | 5% | 5% |

## 筛选流程

1. 用户指定筛选条件（类型、规模区间、业绩要求、风险容忍度、经理年限等）
2. 从数据源获取符合条件的基金列表
3. 剔除规模 < 5000 万（清盘风险）或暂停申购的基金
4. 多维度打分/排名
5. 同公司同策略基金合并（去重）
6. 输出基金比较表及综合排名

## 输出格式

