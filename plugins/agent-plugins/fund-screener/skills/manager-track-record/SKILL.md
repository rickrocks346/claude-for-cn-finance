# 基金经理历史业绩追踪

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金经理信息和基金净值数据。

## 概述

对基金经理的历史管理业绩、从业经历、管理风格变化进行追踪分析。在中国市场，基金经理个人影响力远大于美国市场，此分析尤为重要。

## 中国市场特殊性

| 特征 | 中国 | 美国 | 影响 |
|------|------|------|------|
| 平均任职年限 | 2-3 年 | 5-7 年 | 中国经理更替频繁，业绩记录更短 |
| 一人多基 | 普遍（尤其明星经理同时管 5-10 只） | 较少 | 挂名问题严重，管理精力分散 |
| 跳槽频率 | 高（公募→私募/另一公募→创业） | 中等 | 跳槽后业绩普遍下降 |
| 平台 vs 个人能力 | 难以区分（投研团队支持差异大） | 较易区分（信息更透明） | 大平台经理创业后 Alpha 往往消失 |
| 规模依赖性 | 规模扩大后策略迅速衰减 | 较缓慢 | 中国策略容量普遍更小 |
| 公开披露 | 简历信息少、业绩详细但风格信息不足 | 更全面的披露和访谈 | 需要更多量化推断 |

## 分析维度

### 1. 从业履历深度分析

#### 职业路径
```
研究员 → 基金经理助理 → 基金经理 → 投资总监/副总
```
| 阶段 | 分析要点 |
|------|---------|
| 研究员背景 | 行业研究员出身→行业能力圈（消费/科技/周期等）<br>宏观/固收出身→自上而下思维<br>量化出身→模型驱动 |
| 研究员→基金经理转换 | 研究员期间覆盖的行业是否与后来管理的基金投向一致 |
| 历任公司 | 每段经历在不同平台的表现（判断平台价值 vs 个人价值） |
| 当前公司司龄 | > 3 年 → 较稳定；< 1 年 → 尚在磨合期 |

#### 从业年限分类
| 年限 | 分类 | 评估 |
|------|------|------|
| < 3 年 | 新锐 | 历史短，统计不稳健，需要更多依赖定性判断 |
| 3-5 年 | 中坚 | 有可参考的业绩记录，但不一定覆盖完整牛熊 |
| 5-10 年 | 资深 | 通常覆盖 1-2 个牛熊周期，统计较可靠 |
| > 10 年 | 老将 | 经历多轮周期，但需要关注风格是否老化 |

### 2. 业绩分析体系

#### 绝对业绩指标
| 指标 | 计算 | 评价标准 |
|------|------|---------|
| 任职期总回报 | — | 同类排名 |
| 年化收益率 | 几何年化 | 与业绩基准和同类中位数比较 |
| 滚动 1/3 年收益分布 | 逐月计算滚动收益 | 观察收益的稳定性和极端值 |
| 各年度收益排名 | 按年分桶 | 持续前 1/3 为优秀，忽上忽下为不稳定 |

#### 风险调整业绩
| 指标 | 评价标准 |
|------|---------|
| 年化夏普比率 | > 1 良好，> 2 优秀 |
| 索提诺比率 | > 夏普（说明下行控制好） |
| 信息比率 | > 0.5 有持续超额能力，> 1 优秀 |
| 卡玛比率 | > 1 良好（年化收益 > 最大回撤） |

#### 相对排名
| 指标 | 评价 |
|------|------|
| 同类排名均值 | 持续前 1/3 → 稳定优秀 |
| 同类排名标准差 | 小 → 稳定；大 → 波动大 |
| 排名最差年份 | 后 1/3 的年份数（> 2 年 → 关注） |
| 排名持续性（转移矩阵） | 上年前 1/2 → 今年前 1/2 的概率 |

#### 业绩归因（详见 performance-attribution skill）
- 选股 Alpha vs 行业配置 Beta vs 风格暴露
- 超额收益中制度红利的占比（打新/定增/贴水）

### 3. 管理能力评估

#### 选股能力
```
选股能力 = 持仓股票相对行业的超额收益的加权和
检测方法: Brinson 归因中的"个股选择贡献"
强指标: 连续多季为正、在多个行业中均能选到超额股
```

#### 择时能力
```
择时能力 = 仓位变动是否正确预测了后续市场方向
检测方法: 仓位变动方向 vs 下一季度市场涨跌的匹配度
弱指标: 极少有基金经理展示持续的择时能力（学术共识）
```

#### 行业配置能力
```
行业配置能力 = Σ(实际行业权重 - 基准行业权重) × 行业收益
检测: 相对基准的超低配是否在后续被证明为正确方向
注意: 分散行业配置的经理 vs 行业集中的经理，评价方法不同
```

#### 规模管理能力
```
规模衰减系数 = (规模扩大后年化 Alpha) / (规模较小时年化 Alpha)
> 0.8 → Alpha 衰减不明显
0.5-0.8 → 有一定衰减
< 0.5 → 严重衰减，策略容量已到极限
```
绘制"规模-超额收益散点图"：规模每翻倍，Alpha 下跌多少 bp。

### 4. 风格特征画像

#### 投资风格分类
| 风格维度 | 分类 | 识别方法 |
|---------|------|---------|
| 价值/成长 | 深度价值 / 相对价值 / GARP / 成长 / 激进成长 | 持仓加权 PE/PB/股息率 + 因子暴露 |
| 大盘/小盘 | 大盘 / 中盘 / 小盘 / 微盘 | 持仓市值中位数 |
| 集中/分散 | 集中(CR10>60%) / 适度集中(40-60%) / 分散(<40%) | 持仓集中度 |
| 行业倾向 | 行业专才 / 多行业 / 宏观驱动 | 行业轮动频率 + 行业集中度 |
| 换手率 | 低(<100%) / 中(100-300%) / 高(>300%) | 年报/中报推算 |
| 自上而下/自下而上 | 宏观驱动 / 选股驱动 | 归因中行业配置贡献 vs 选股贡献 |

#### 风格稳定性
- 风格在近 3-5 年是否保持一致（见 style-drift skill）
- 擅长/不擅长的市场环境
- 规模增长后风格是否被迫变化（小盘→大盘是常见路径）

### 5. 风险特征

#### 回撤分析
| 指标 | 分析 |
|------|------|
| 任职期最大回撤 | 绝对值（< 20% 良好，20-40% 可接受，> 40% 高波动） |
| 回撤期间特征 | 回撤是由市场系统性下跌还是个股/行业集中造成的？ |
| 回撤修复天数 | < 6 个月优秀，6-12 月可接受，> 12 月 → 关注 |
| 最大回撤发生后的操作 | 是否在底部减仓（最差操作）/继续持有/加仓（最好但极少） |
| 回撤与同类比较 | 同期同类排名（跑赢=风控好，跑输=风控差） |

#### 极端事件表现
选取 A 股近年代表性极端事件（如 2015 年股灾、2016 年熔断、2018 年全年下跌、2020 年 3 月 COVID 急跌、2022 年 1-4 月下跌、2024 年 2 月急跌），分析该期间基金经理的操作和表现。

#### 离职风险
| 信号 | 风险 |
|------|------|
| 同时管理 > 8 只基金 | 管理精力分散，可能准备"交班" |
| 公司投研团队核心人员离职 | 支持体系弱化 |
| 管理规模增速异常（翻倍/季） | 被动调整策略，业绩可能恶化 |
| 社交媒体活跃度异常增加 | 可能考虑创业/跳槽 |
| 近 1 年业绩大幅落后同类 | 离职或被换的概率增加 |

### 6. 平台因素剥离
判断 Alpha 是来自个人还是平台：
```
个人 Alpha = 本基金超额 - 同公司同策略其他基金的平均超额
> 0 → 有个人 Alpha
≈ 0 → 业绩主要来自平台/团队
< 0 → 个人表现不如公司同策略平均水平
```

## 多基金管理分析

当经理同时管理多只基金时：
| 分析项 | 方法 |
|--------|------|
| 业绩一致性 | 同类型基金在各时间段的收益离散度（标准差越小越好） |
| 持仓一致性 | 同类型基金的重仓股重合度（> 80% 说明复制策略） |
| 管理费加权 | 是否把最好业绩给了旗舰基金（可能是有意也可能是统计偏差） |

**挂名基金识别信号**：
- 基金经理任职不足 1 年但基金宣传以该经理为主
- 同经理管理的基金风格差异巨大（说明不同基金由不同人实际操作）
- 基金经理同时管理 > 8 只基金（物理上不可能深入研究所有持仓）

## 分析流程

1. 获取基金经理管理的全部基金列表及任职起止日
2. 获取各基金在任职期间的净值数据（日频）
3. 计算任职期年化收益、波动、夏普、回撤等核心指标
4. 计算相对基准和同业的超额收益及排名
5. 归因分析（Brinson/因子）
6. 评估选股/择时/行业配置/规模管理能力
7. 划分风格并评估风格稳定性
8. 分析回撤特征和极端事件表现
9. 剥离平台因素
10. 输出经理画像报告
