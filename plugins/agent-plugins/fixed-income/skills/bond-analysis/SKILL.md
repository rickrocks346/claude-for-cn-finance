# 债券基本面分析与估值

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取债券数据。

## 概述

对中国债券市场的主要品种进行基本面分析和估值计算，涵盖利率债和信用债。核心分析框架：品种识别 → 估值计算 → 信用分析（信用债）→ 相对价值判断。

## 中国债券市场结构

### 市场分层
| 市场 | 主要品种 | 参与者 | 交易方式 |
|------|---------|--------|---------|
| 银行间市场 | 国债、政金债、信用债、同业存单 | 银行、保险、基金、券商 | 一对一询价/请求报价 |
| 交易所市场 | 国债、公司债、可转债/可交债 | 券商、基金、个人（合格投资者） | 竞价撮合 |
| 柜台市场 | 国债、地方政府债 | 个人（储蓄国债） | 银行柜台 |

### 主要品种详解
| 品种 | 发行人 | 信用风险 | 流动性 | 税收 | 个人可投 |
|------|--------|---------|--------|------|---------|
| 国债 | 财政部 | 无（主权信用） | 高 | 免利息税 | 是（储蓄国债/记账式） |
| 地方政府债 | 省级政府（一般债/专项债） | 极低 | 中 | 免利息税 | 是（柜台） |
| 政策性金融债（政金债） | 国开行/农发行/进出口行 | 极低（准主权） | 高 | 不免 | 否（银行间为主） |
| 同业存单 | 商业银行 | 低（银行信用） | 高 | 不免 | 否 |
| 中期票据(MTN) | 企业（非金融） | 中-高 | 中 | 不免 | 否（银行间为主） |
| 公司债 | 企业/上市公司 | 中-高 | 低-中 | 不免 | 是（合格投资者） |
| 企业债 | 央企/地方国企为主 | 中 | 低 | 不免 | 否（银行间为主） |
| 短期融资券(CP/SCP) | 企业 | 中 | 中 | 不免 | 否 |
| 资产支持证券(ABS) | SPV | 取决于底层资产 | 低 | 不免 | 否（合格投资者） |
| 可转债/可交债 | 上市公司/股东 | 中（但股性更强） | 中-高 | 不免 | 是 |

## 债券估值核心指标

### 1. 价格相关
| 术语 | 含义 | 中国惯例 |
|------|------|---------|
| 净价 (Clean Price) | 不含应计利息的价格 | 交易所报价为净价 |
| 全价 (Dirty Price) | 净价 + 应计利息 | 银行间报价为全价 |
| 应计利息 | 上次付息日至结算日的票息积累 | = 票面利率 × 计息天数 / 年度天数 |
| 面值 | 通常 100 元 | 中国标准面值 100 元 |

### 2. 到期收益率 (YTM)
```
P = Σ(C/f / (1+y/f)^t) + FV / (1+y/f)^n
```
其中：P=全价，C=年票息，f=年付息次数，y=YTM，FV=面值，n=剩余付息次数

### 3. 久期指标
| 指标 | 公式 | 含义 | 应用 |
|------|------|------|------|
| 麦考利久期 | Σ(t × PV(CF_t)) / Σ(PV(CF_t)) | 现金流加权平均回收时间（年） | 资产负债匹配 |
| 修正久期 | MacD / (1 + y/f) | 利率变动 1% 对应价格变动近似 % | 利率风险管理 |
| 有效久期 | (P_down - P_up) / (2 × P0 × Δy) | 含权债的利率敏感度 | 可赎回债/ABS |
| 关键利率久期 | 特定期限利率变动对价格的影响 | 非平行移动下的风险 | 曲线策略 |
| DV01 | 修正久期 × 全价 × 0.0001 | 利率变动 1bp 对应的价格变动（元） | 交易和风控 |

### 4. 凸性
```
凸性 ≈ [P_up + P_down - 2×P0] / [P0 × (Δy)²]

价格变动 ≈ -修正久期 × Δy + 0.5 × 凸性 × (Δy)²
```
- 修正久期给出一阶近似（线性），大幅利率变动需凸性修正
- 凸性越大 → 债券的"涨多跌少"特性越强
- 零息债凸性 > 附息债凸性（同久期下）

### 5. 信用利差
| 利差类型 | 计算 | 含义 |
|---------|------|------|
| 名义利差 | 信用债 YTM - 同期限国债 YTM | 最简单，但未分离期权和税收影响 |
| Z-Spread (零波动利差) | 在国债即期曲线上平行加 X bp → 折现价 = 市价 | 分离了收益率曲线形状的影响 |
| OAS (期权调整利差) | Z-Spread - 期权价值 | 含权债的纯信用利差（剔除期权影响） |
| I-Spread | 信用债 YTM - 同期限掉期利率 | 以掉期利率为基准，常用于欧洲（中国不常用） |
| G-Spread | 信用债 YTM - 插值国债 YTM | 中国最常用 |

## 信用债分析框架

### 发行人基本面分析
| 维度 | 核心指标 | 警戒线 |
|------|---------|--------|
| 盈利能力 | EBITDA/利息支出（利息覆盖倍数） | < 2x → 关注，< 1x → 危险 |
| 杠杆水平 | 资产负债率、有息负债/EBITDA | 有息负债/EBITDA > 5x → 高杠杆 |
| 流动性 | 货币资金/短期有息负债、速动比率 | < 0.5 → 短期偿债压力大 |
| 现金流质量 | 经营活动现金流/有息负债 | < 0.1 → 靠借新还旧 |
| 资产质量 | 应收账款周转、存货周转、受限资产比例 | 受限资产/总资产 > 50% → 融资空间有限 |

### 行业分析
| 行业 | 关键关注点 |
|------|----------|
| 城投 | 区域财政实力、平台层级（省/市/区）、政府支持力度、隐性债务化解方案 |
| 房地产 | 合约销售、土储质量、三条红线指标、融资渠道通畅度 |
| 煤炭/钢铁 | 资源储量、成本优势、行业周期位置、供给侧改革受益程度 |
| 制造业 | 行业景气度、技术壁垒、下游集中度、出口依赖度 |

### 评级体系
| 评级 | AAA | AA+ | AA | AA- 及以下 |
|------|-----|-----|-----|----------|
| 含义 | 偿债能力极强 | 很强 | 强 | 一般/较弱 |
| 收益率加点(vs 国债) | +30-80bp | +50-150bp | +80-250bp | +150bp+ |
| 警示 | — | — | — | AA- 是投资级门槛，以下为投机级 |

> [来源: 中国人民银行/中国债券信息网] 中国国内评级普遍偏高，同一家公司的国际评级通常比国内评级低 3-6 个 notch。做信用分析时不要仅依赖评级。

### 增信措施分析
| 增信方式 | 分析要点 |
|---------|---------|
| 第三方担保（连带责任） | 担保方信用评级、担保方与发行人的关联关系、担保是否经股东会批准 |
| 抵质押担保 | 抵押资产评估价值/债券规模（覆盖率 > 1.2x 较好）、资产流动性、是否重复抵押 |
| 信用风险缓释工具(CRMW) | 创设机构的信用、CRMW 覆盖比例 |
| 差额补足/流动性支持 | 承诺方的信用和履约能力 |

### 条款分析
| 条款类型 | 有利方 | 分析要点 |
|---------|--------|---------|
| 回售权 (Put) | 投资者 | 回售价格、回售时间窗口、行权收益率 |
| 赎回权 (Call) | 发行人 | 赎回价格、赎回条件（通常利率下降时发行人会赎回再融资） |
| 调整票面利率 | 发行人 | 回售前的利率调整方向（不调高 → 被迫回售） |
| 交叉违约 | 投资者 | 违约触发条件范围、宽限期、豁免机制 |
| 事先约束 | 投资者 | 限制新增债务、限制资产出售、限制分红 |
| 控制权变更 | 投资者 | 控制权变更触发回售——并购/重组场景的关键保护 |

## 利率债分析要点

| 品种 | 核心分析框架 |
|------|-----------|
| 国债 | 久期定位、曲线形态、供给节奏（财政部发行计划）、外资流入 |
| 政金债 | 相对国债的利差（隐含税收+流动性溢价）、发行节奏 |
| 地方债 | 区域信用分化（虽然名义上无风险但市场已开始定价区域差异）、一级发行利差 |
| 同业存单 | SHIBOR/DR007 走势、银行负债端压力、季末时点效应 |

## 分析流程

1. 确定债券代码，获取基本信息（类型、发行人、票面、期限、评级）
2. 计算核心估值指标（净价/全价/YTM/久期/凸性）
3. 信用债：深入分析发行人基本面、行业环境、增信措施和条款保护
4. 与同期限、同评级、同行业的可比债券比较信用利差
5. 分析利差所处的历史分位，判断相对价值
6. 识别关键风险（信用风险/利率风险/流动性风险/条款风险）
7. 输出债券分析报告
