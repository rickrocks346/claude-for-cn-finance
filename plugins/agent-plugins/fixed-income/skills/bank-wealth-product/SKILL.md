# 银行理财产品分析

> 中国银行理财市场已全面净值化。本文档提供分析框架和关键指标，帮助理解净值化时代的产品特征和风险。

## 概述

对银行理财产品进行分析和比较，帮助用户理解净值化转型后的产品特征、风险和收益来源。

## 中国银行理财市场背景

### 资管新规核心变化（2018 年发布，2022 年起全面实施）
| 变化 | 旧规则 | 新规则 | 对投资者的影响 |
|------|--------|--------|-------------|
| 估值方法 | 摊余成本法为主 | 市值法为主（部分封闭式产品可用摊余成本） | 净值有波动，不再"稳赚不赔" |
| 刚兑 | 银行隐性担保 | 禁止刚兑 | 投资者自担风险 |
| 期限匹配 | 资金池运作 | 非标资产期限须匹配产品期限 | 产品期限拉长、流动性降低 |
| 产品形态 | 预期收益型 | 净值型 | 收益不确定，需看历史业绩和波动 |
| 嵌套限制 | 多层嵌套 | 仅允许一层嵌套 | 通道业务大幅压缩 |
| 理财子公司 | 银行资管部 | 独立法人理财子公司 | 与母行风险隔离 |

### 银行理财子公司
| 类型 | 代表 | 特点 |
|------|------|------|
| 大行理财子 | 工银理财、建信理财、中银理财等 | 规模大、产品线全、风格稳健 |
| 股份行理财子 | 招银理财、兴银理财、信银理财等 | 市场化程度高、产品创新多 |
| 城商行理财子 | 宁银理财、杭银理财等 | 区域特色、规模较小 |
| 合资理财子 | 贝莱德建信、高盛工银等 | 外资管理经验+中资渠道 |

## 常见产品类型

| 类型 | 风险等级 | 主要投向 | 波动特征 | 适合投资者 |
|------|---------|---------|---------|----------|
| 现金管理类 | R1 | 货币市场工具（存单、逆回购、短债） | 极低波动（日收益几乎无负） | 活钱管理 |
| 纯固收类（短期限） | R2 | 存款+短债+同业存单 | 低波动（最大回撤 < 0.3%） | 稳健型 |
| 纯固收类（中长期限） | R2 | 存款+债券+少量非标 | 中低波动（最大回撤 < 0.5%） | 稳健型 |
| 固收增强类 | R2-R3 | 债券为主(80-95%)+少量权益/转债/衍生品(5-20%) | 中低波动 | 平衡型 |
| 混合类 | R3-R4 | 股债混合（权益 20-80%） | 中等波动 | 进取型 |
| 权益类 | R4-R5 | 股票为主（权益 > 80%） | 中高波动 | 积极型 |
| 商品及衍生品类 | R4-R5 | 商品、衍生品 | 高波动 | 专业投资者 |
| 养老理财 | R2-R3 | 股债混合+长期限设计 | 中低波动 | 养老储备 |

### 投资者适当性匹配（中国监管框架）
| 投资者类型 | 风险承受等级 | 可购买产品风险等级 |
|-----------|------------|-----------------|
| 保守型 | C1 | R1 |
| 稳健型 | C2 | R1-R2 |
| 平衡型 | C3 | R1-R3 |
| 进取型 | C4 | R1-R4 |
| 积极型 | C5 | R1-R5 |

## 分析维度

### 1. 收益指标
| 指标 | 适用产品 | 计算 | 说明 |
|------|---------|------|------|
| 近 7 日年化收益率 | 现金管理类 | 近 7 天收益年化 | 短期波动大，参考价值有限 |
| 万份收益 | 现金管理类 | 每日万份基金的收益（元） | 更直观 |
| 近 1/3/6/12 月年化收益率 | 全部 | — | 核心收益指标 |
| 成立以来年化收益率 | 全部 | 几何年化 | 覆盖产品整个生命周期 |
| 业绩比较基准 | 全部（合同约定） | — | 管理人的收益目标，不等于承诺收益 |

**业绩比较基准的类型**：
| 类型 | 示例 | 含义 |
|------|------|------|
| 固定数值型 | "3.00%" | 基准为固定值 |
| 区间数值型 | "2.50%-4.50%" | 基准为一个区间 |
| 指数挂钩型 | "中债总财富指数×90%+沪深300×10%" | 基准跟随市场波动 |

### 2. 风险指标
| 指标 | 含义 | 各类型警戒线 |
|------|------|------------|
| 净值最大回撤 | 历史最大峰谷跌幅 | 纯固收 < 0.5%、固收增强 < 3%、混合 < 10% |
| 年化波动率 | 日收益率的年化标准差 | 纯固收 < 1%、固收增强 < 3% |
| 负收益天数占比 | 近 1 年净值下跌天数/总交易日 | 纯固收 < 5%、固收增强 < 15% |
| 跌破净值（< 1.0000） | 净值低于面值的持续天数 | 越长越说明风控不足 |
| 最大连续负收益天数 | — | — |

### 3. 产品要素
| 要素 | 分析要点 |
|------|---------|
| 风险等级（R1-R5） | 匹配投资者适当性 |
| 起购金额 | 1 元/1 万元/100 万元起——门槛决定可及性 |
| 投资期限 | T+1（随时）/7 天/1 月/3 月/6 月/1 年/3 年+ |
| 开放频率 | 每日开放 / 定期开放（每月/每季/每半年） / 封闭期 |
| 申赎规则 | 申购确认日（T+?)、赎回到账日（T+?)、巨额赎回限制 |
| 提前赎回限制 | 是否允许提前赎回、提前赎回费率 |
| 产品规模 | 规模过小（< 1 亿）→ 运营成本覆盖困难、可能清盘 |

### 4. 费用结构
| 费用类型 | 典型费率 | 说明 |
|---------|---------|------|
| 固定管理费 | 0.15-0.50%/年 | 按产品规模收取 |
| 托管费 | 0.02-0.05%/年 | 托管行收取 |
| 销售服务费 | 0.10-0.50%/年 | 销售机构收取（有些产品不收取） |
| 超额业绩报酬 | 超出业绩基准部分的 X%（通常 20-80%） | 管理人激励——比例越高对投资者越不利 |
| 申购/认购费 | 0-1.0%（部分产品） | 净值型产品申购费逐步取消 |
| 赎回费 | 0-2.0%（持有期越短赎回费越高） | 惩罚短期交易 |
| **综合费率** | **0.30-1.50%/年** | 所有固定费率之和 |

**费用视角的简易比较**：
```
投资者实际到手收益 ≈ 产品费后净值增长率
                     ≈ 产品底层资产收益率 - 综合费率 - 超额报酬计提
```

### 5. 投资组合信息（产品季报/年报）
| 分析维度 | 关注点 |
|---------|--------|
| 大类资产配置 | 存款/债券/非标/权益/其他 各占比 |
| 债券组合 | 利率债 vs 信用债、评级分布、久期 |
| 非标资产 | 占比、融资主体、剩余期限 |
| 前十大持仓 | 如披露，关注集中度和信用质量 |
| 杠杆率 | 理财产品通常杠杆率 120-140%（债券质押回购） |

### 6. 管理人和销售机构
| 分析维度 | 关注点 |
|---------|--------|
| 管理人管理规模 | 同类产品规模及排名 |
| 同类产品历史业绩 | 该管理人同类型产品平均表现 |
| 合规与风险事件 | 是否有被监管处罚/产品净值异常波动历史 |
| 销售机构 | 银行/券商/互联网平台 |

## 现金管理类 vs 货币基金深度对比

| 特征 | 现金管理类理财 | 货币基金 |
|------|--------------|---------|
| 监管机构 | 国家金融监管总局 | 证监会 |
| T+0 快速赎回 | 多家银行仍支持（每日限额不等） | 单只每日限额 1 万元 |
| 投资范围 | 略宽于货基 | 严格限定（剩余期限 ≤ 397 天） |
| 久期限制 | ≤ 120 天 | ≤ 120 天 |
| 杠杆上限 | 120% | 120% |
| 起购金额 | 通常 1 元起（部分 1 万元起） | 1 元起（基本无门槛） |
| 购买渠道 | 银行 APP | 多平台（蚂蚁/微信/银行/券商） |
| 收益比较 | 通常略高于货基（投资范围优势） | 略低 |

## 净值化时代的产品"避坑指南"

### 常见陷阱
| 陷阱 | 识别方法 |
|------|---------|
| "业绩比较基准"当"预期收益率" | 基准不等于承诺——看历史实际收益和波动 |
| "近 7 日年化"误导 | 短期收益被年化放大，看近 3 月/6 月更稳定 |
| 封闭期内净值"平稳" | 封闭期内可能用摊余成本法估值，开放日才反映真实市值 |
| 超额报酬计提过高 | 超额部分的 80% 归管理人 → 管理人赚了、投资者只拿了个"稳" |
| 非标资产"隐蔽"风险 | 理财投非标（房地产/城投）、暴雷后净值一次性大跌 |
| 流动性错配 | 短期开放但底层资产流动性差 → 巨额赎回时可能暂停赎回 |

### 净值异常波动排查
| 异常类型 | 可能原因 |
|---------|---------|
| 净值突然跳涨（一日 > 0.3%） | 非标资产到期兑付、债券估值调整、份额折算 |
| 净值突然大跌（一日 > 0.3%） | 信用债违约/估值下调、权益市场大跌（含权益类）、大额赎回费计入 |
| 净值长期"走直线"（波动为 0） | 使用摊余成本法估值（封闭期）或现金管理类产品 |

## 分析流程

1. 获取产品说明书/概要（产品类型、风险等级、投资范围、费用结构）
2. 确认产品类型和风险等级与投资者适当性的匹配
3. 获取历史净值数据，计算收益和风险指标（近 3/6/12 月、成立以来）
4. 分析费用结构——计算综合费率（所有固定费用之和）和超额报酬条款
5. 获取最新季报/年报——分析大类资产配置和重仓资产
6. 如做比较：同类型多产品横向对比（收益、风险、费率、规模）
7. 提供净值异常波动说明（如有）
8. 输出产品分析报告

## 公开来源补充内容（post8b）

### 银行理财净值化转型与2022年破净事件

**资管新规背景**：2018年4月《资管新规》发布，要求银行理财产品向净值型转型，打破刚兑。过渡期至2021年底，理财产品逐步告别"预期收益率"模式。

**2022年11月-12月理财破净事件**：
- **触发原因**：债市大幅调整，10年期国债收益率快速上行，理财产品底层债券资产价格下跌
- **破净规模**：市场一度约30%的理财产品净值跌破1，引发投资者赎回潮
- **连锁反应**：赎回潮→被迫卖出债券→债券价格进一步下跌→更多产品破净（负反馈螺旋）
- **市场教育意义**：净值化转型后投资者首次大规模感受到理财净值波动风险，打破"保本保收益"固有认知

**银行理财产品分类（资管新规后）**

| 类型 | 风险等级 | 底层资产主要构成 | 特点 |
|------|---------|--------------|------|
| 现金管理类 | R1（低风险）| 货币市场工具 | 类货基，流动性高，T+0/T+1 |
| 固收类 | R2-R3 | 债券为主 | 主流产品，净值波动较小但非零 |
| 混合类 | R3-R4 | 债券+权益 | 净值波动较大 |
| 权益类 | R4-R5 | 股票为主 | 规模较小，波动大 |
| 衍生品类 | R5 | 衍生金融工具 | 极少数高风险产品 |
