# 投资组合集中度分析

> 集中度是组合风险的重要来源。本 skill 提供多维度的集中度分析方法。
> 只做描述性分析，不提供调仓建议。

## 概述

对用户投资组合进行多维度的集中度分析，识别组合在个股、行业、地域、资产类别、风格上的过度集中。

## 集中度指标

### 1. 赫芬达尔-赫希曼指数 (HHI)
```
HHI = Σ(wi²)，wi = 第 i 个持仓的权重
```
| HHI 范围 | 集中度判断 |
|---------|----------|
| < 500 | 高度分散（组合中有 20+ 只等权标的） |
| 500-1000 | 适度集中 |
| 1000-2500 | 较集中（5-10 只核心持仓） |
| > 2500 | 高度集中（3-4 只重仓） |

### 2. 前 N 大持仓占比
- CR3 / CR5 / CR10（前 3/5/10 大持仓累计权重）
- 如果前 3 大持仓占比 > 50%，组合显著集中

### 3. 行业集中度
- 按申万一级行业汇总持仓权重
- 单行业 > 30% → 行业集中风险
- 单行业 > 50% → 显著行业集中风险

### 4. 资产类别集中度
- 股票 / 债券 / 货币 / 其他大类资产占比
- 某一类别 > 80% → 资产类别集中

### 5. 市值风格集中度
- 按大盘/中盘/小盘分类汇总
- 单一市值风格 > 70% → 风格集中

### 6. 地域集中度
- A股 / 港股 / 美股 / 其他
- 单一市场 > 80% → 地域集中（尤其对于"全球配置"型组合）

## 集中度分析维度

| 维度 | 指标 | 预警阈值 |
|------|------|---------|
| 个股 | CR3/CR5/HHI | CR3 > 40% 或 HHI > 1500 |
| 行业 | 单行业最大占比 | > 30% |
| 资产类别 | 大类资产占比 | > 80% |
| 市值 | 单一市值风格 | > 70% |
| 地域 | 单一市场 | > 80% |
| 信用评级 | 非投资级占比 | > 20%（固收组合） |

## 分析流程

1. 获取用户组合的持仓和权重
2. 按个股维度计算 CR3/CR5/HHI
3. 按申万行业分类汇总行业权重
4. 按资产类别/市值/地域分类汇总
5. 识别所有超过预警阈值的维度
6. 输出集中度分析报告
