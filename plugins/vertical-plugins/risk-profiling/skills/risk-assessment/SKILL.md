# 投资组合风险指标计算

> 本 skill 计算投资组合的核心风险指标。用户提供组合持仓和权重后，自动计算并解读各项指标。
> 只做描述性分析，不提供调仓建议。

## 概述

对用户提供的投资组合进行系统性的风险指标计算，覆盖波动率、回撤、夏普比率、VaR、相关性等维度。

## 核心风险指标

### 1. 波动率（年化）
```
年化波动率 = 日收益率标准差 × sqrt(252)
```
- 中国 A 股年化波动率通常在 15-30%
- 债券型组合波动率通常 < 5%
- 混合型组合波动率在 5-15%

### 2. 最大回撤 (Maximum Drawdown)
```
MDD = max( (峰值 - 谷值) / 峰值 )
```
- 回撤修复天数（从谷值回到前高所需时间）
- 中国市场的回撤深度和频率都高于成熟市场

### 3. 夏普比率
```
夏普比率 = (年化收益 - 无风险利率) / 年化波动率
```
- 中国市场无风险利率通常用 10 年期国债收益率
- 衡量每单位波动率带来的超额收益

### 4. 索提诺比率
```
索提诺比率 = (年化收益 - 无风险利率) / 下行波动率
```
- 仅考虑下行波动（负收益的波动）
- 比夏普比率更关注投资者真正关心的风险

### 5. VaR（在险价值）
```
VaR(95%, 1天) = 在 95% 置信度下，组合单日最大可能亏损
```
- 历史模拟法：用历史日收益的分位数
- 参数法：假设正态分布，VaR = μ + Z_0.05 × σ
- 蒙特卡洛法：对复杂组合更准确

### 6. CVaR（条件在险价值/Expected Shortfall）
```
CVaR(95%) = 超过 VaR 的亏损的平均值
```
- 衡量"最坏的 5% 情况下"的平均亏损

### 7. Beta
```
β = Cov(R_portfolio, R_benchmark) / Var(R_benchmark)
```
- 一般以沪深 300（大盘）或中证全指为基准
- β > 1 → 组合波动大于市场
- β < 1 → 组合波动小于市场

### 8. 相关性矩阵
- 持仓之间的 Pearson 相关系数
- 高相关性 → 分散化效果差
- 理想状态下，资产间相关性越低越好

## 分析流程

1. 用户提供组合持仓和权重（或上传 Excel/CSV）
2. 获取各持仓的历史价格数据
3. 计算组合日收益率序列（权重 × 各持仓收益率求和）
4. 逐一计算风险指标
5. 解读各指标的含义和所处的区间
6. 输出风险指标一览表
