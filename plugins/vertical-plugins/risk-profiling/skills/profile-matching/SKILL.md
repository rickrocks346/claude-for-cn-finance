# 风险偏好与组合匹配度诊断

> **核心功能**：将用户投资组合的实际风险特征与其声明的风险偏好等级进行对比，诊断匹配度。
> **关键合规约束**：只输出描述性诊断和方向性提示，绝对不输出具体调仓建议。

## 概述

基于中国基金销售适当性管理的五级风险偏好分类体系（C1-C5），将用户投资组合的实际特征与对应等级的典型配置区间对比，诊断偏离方向和程度。

## 法规背景

参考文件：
- 《证券期货投资者适当性管理办法》（证监会令第 130 号，2017 年 7 月 1 日施行）[来源: 证监会]
- 《基金募集机构投资者适当性管理实施指引（试行）》（2017）[来源: 中国证券投资基金业协会]
- 专业投资者 vs 普通投资者的分类标准

## 五级风险偏好分类标准

### C1 — 保守型（保本优先）
| 维度 | 典型区间 |
|------|---------|
| 风险承受意愿 | 不接受本金损失 |
| 投资目标 | 本金安全 + 流动性 |
| 权益类（股票/股基） | 0-10% |
| 固收类（债基/理财/存款） | 70-100% |
| 货币类（货基/现金） | 0-30% |
| 年化波动率 | < 3% |
| 预期最大回撤 | < 3% |
| 推荐持有期 | 任何期限 |
| 典型产品 | 银行存款、货币基金、短期纯债基金、R1 理财 |

### C2 — 稳健型（小幅波动可接受）
| 维度 | 典型区间 |
|------|---------|
| 风险承受意愿 | 接受小幅波动，追求略高于通胀的回报 |
| 投资目标 | 保值基础上追求适度增值 |
| 权益类 | 5-20% |
| 固收类 | 50-85% |
| 货币类 | 0-20% |
| 年化波动率 | 3-6% |
| 预期最大回撤 | 3-8% |
| 推荐持有期 | 6 个月以上 |
| 典型产品 | 纯债基金、固收+、银行 R2 理财、二级债基 |

### C3 — 平衡型（中等波动可接受）
| 维度 | 典型区间 |
|------|---------|
| 风险承受意愿 | 接受中等波动 |
| 投资目标 | 资本稳健增长 |
| 权益类 | 20-50% |
| 固收类 | 40-70% |
| 货币类 | 0-15% |
| 年化波动率 | 6-12% |
| 预期最大回撤 | 8-18% |
| 推荐持有期 | 1 年以上 |
| 典型产品 | 混合基金（偏债/平衡）、偏股混合、指数基金 |

### C4 — 积极型（较大波动可接受）
| 维度 | 典型区间 |
|------|---------|
| 风险承受意愿 | 接受较大波动，追求长期增值 |
| 投资目标 | 长期资本增值 |
| 权益类 | 50-80% |
| 固收类 | 10-40% |
| 货币类 | 0-10% |
| 年化波动率 | 12-20% |
| 预期最大回撤 | 18-30% |
| 推荐持有期 | 3 年以上 |
| 典型产品 | 股票基金、指数基金、行业 ETF、私募基金 |

### C5 — 激进型（剧烈波动可接受）
| 维度 | 典型区间 |
|------|---------|
| 风险承受意愿 | 接受剧烈波动，追求最大化收益 |
| 投资目标 | 最大化资本增值 |
| 权益类 | 80-100% |
| 固收类 | 0-20% |
| 货币类 | 0-10% |
| 年化波动率 | 18-30%+ |
| 预期最大回撤 | 25-50%+ |
| 推荐持有期 | 5 年以上 |
| 典型产品 | 全权益组合、衍生品、杠杆型产品、PE/VC |

## 匹配度诊断方法

### 诊断维度（6 个维度）
| # | 维度 | 指标 | 方法 |
|----|------|------|------|
| 1 | 资产配置偏离 | 权益/固收/货币/其他实际 vs 典型区间 | 大类资产占比对比 |
| 2 | 波动率偏离 | 组合实际/隐含波动率 vs 等级的波动率范围 | 历史波动率或持仓加权波动率 |
| 3 | 回撤偏离 | 组合历史/预期最大回撤 vs 等级回撤范围 | 历史回撤或压力测试估算 |
| 4 | 集中度偏离 | CR3/CR5/HHI 是否合理 | 单一个股/行业/风格集中度 |
| 5 | 流动性偏离 | 封闭/定开类占比 vs 流动性需求 | 资金锁定期 vs 投资期限匹配 |
| 6 | 期限匹配 | 组合推荐持有期 vs 等级推荐持有期 | 产品期限 vs 投资目标 |

### 综合偏离度评分
对每个维度打分（0=完全匹配，1=轻度偏离，2=显著偏离）：
```
综合偏离度 = Σ(维度得分 × 权重)
权重: 资产配置 30% + 波动率 25% + 回撤 25% + 集中度 10% + 流动性 5% + 期限 5%
```
| 综合偏离度 | 评级 | 含义 |
|-----------|------|------|
| 0-0.3 | 匹配 | 各维度在典型区间内 |
| 0.3-0.7 | 轻度偏离 | 个别维度略有超出 |
| 0.7-1.2 | 中度偏离 | 多个维度明显超出 |
| > 1.2 | 显著偏离 | 组合实际风险特征与声明等级严重不符 |

### 特殊情境考量
| 情景 | 处理 |
|------|------|
| 用户有多个组合（如不同用途：养老、教育、储蓄） | 分别评估每个组合的匹配度 |
| 用户组合中含有类固收替代品（REITs、高股息股） | 需判断实质风险特征而非只看名义类别 |
| 用户投资经验丰富但风险偏好填的低 | 在诊断中标注"投资经验与实际风险偏好可能不一致" |
| 组合中持有大量非标/另类资产 | 非标缺乏连续估值，用流动性+信用风险替代波动率 |

## 输出格式规范（合规关键）

### 允许的诊断输出模式
- "你的组合权益类实际占比 X%，落在 [C级] 的典型区间内/高于上限 Y%/低于下限 Z%"
- "你的组合年化波动率 X%，处于 [C级] 典型区间的 [位置]"
- "从风险特征看，你的组合更接近 [C级] 而非你声明的 [C级]"
- "当前组合的波动和回撤水平高于/低于你声明的 [C级] 通常可承受的范围"

### 绝对禁止的输出
| 禁止 | 示例 |
|------|------|
| 仓位调整建议 | "建议将权益占比从 85% 调整至 30%" |
| 具体标的推荐 | "建议买入 XX 债券基金来降低波动" |
| 买卖时点建议 | "建议在当前时点减仓股票" |
| 目标配置方案 | "建议将组合调整为 40% 股票 + 60% 债券" |
| 隐含的业绩预测 | "调整后组合预期年化 6-8%" |

## 分析流程

1. 用户提供投资组合 + 声明的风险偏好等级（C1-C5）
2. 计算组合的实际资产配置比例
3. 计算组合的实际风险指标（波动率、回撤等）
4. 计算集中度、流动性、期限匹配指标
5. 与声明等级的标准区间逐一对比
6. 计算综合偏离度评分
7. 输出诊断报告（仅描述性 + 方向性提示）

## 输出格式

```
## 风险匹配度诊断 ({日期})

### 你声明的风险偏好: {C 级} — {保守型/稳健型/平衡型/积极型/激进型}

### 组合实际特征
| 维度 | 实际值 | {C级}典型区间 | 匹配状态 |
|------|--------|-------------|---------|
| 权益类占比 | X% | X%-Y% | 匹配/偏低/偏高 |
| 固收类占比 | X% | X%-Y% | ... |
| 货币类占比 | X% | X%-Y% | ... |
| 年化波动率 | X% | X%-Y% | ... |
| 最大回撤 | -X% | -X%~-Y% | ... |
| 前3大持仓集中度 | X% | — | ... |
| 封闭/定开占比 | X% | — | ... |

### 综合偏离度: X/2.0 → [匹配 / 轻度偏离 / 中度偏离 / 显著偏离]

### 各维度诊断
**资产配置偏离**
- 权益类实际占比 X%，高于/低于 {C级} 典型区间的上限/下限
- ...

**风险指标偏离**
- 组合年化波动率 X%，处于 {C级} 典型区间 X-Y% 的 [位置]
- ...

**集中度特征**
- 前三大持仓占比 X%，集中度偏高/适中/偏低
- 行业集中度：XX 行业占比 X%（正常/偏高）

**其他维度**
- ...

### 方向性提示
- 当前组合的波动和回撤水平高于/低于/匹配你声明的 {C级} 通常可承受的范围
- 组合的收益弹性也相应更高/更低
- 持有期是否匹配：你组合中 X% 为封闭/定开类产品，平均锁定期 X 月

⚠️ 免责声明：以上诊断为风险特征描述性分析，仅供参考，不构成任何投资建议。
本诊断不提供调仓方案或投资推荐。投资有风险，决策需谨慎。
```

## 合规边界
- [ ] 不包含具体标的推荐
- [ ] 不包含买卖时点建议
- [ ] 不包含仓位配置建议（不输出调仓方案/目标配置）
- [ ] 所有分析结果附带免责声明
- [ ] 不要求用户提供证券账户信息
