# 风险偏好与组合匹配度诊断

> **核心功能**：将用户投资组合的实际风险特征与其声明的风险偏好等级进行对比，诊断匹配度。
> **关键合规约束**：只输出描述性诊断和方向性提示，绝对不输出具体调仓建议。

## 概述

基于中国基金销售适当性管理的五级风险偏好分类体系，将用户投资组合的实际特征与对应等级的典型配置区间对比，诊断偏离方向和程度。

## 五级风险偏好分类标准

参考《证券期货投资者适当性管理办法》和公募基金销售适当性管理指引。

### C1 — 保守型
| 维度 | 典型特征 |
|------|---------|
| 风险承受意愿 | 不接受本金损失 |
| 投资目标 | 本金安全 + 流动性 |
| 权益类区间 | 0-10% |
| 固收类区间 | 70-100% |
| 货币类区间 | 0-30% |
| 年化波动率范围 | < 3% |
| 预期最大回撤 | < 3% |
| 典型产品 | 银行存款、货币基金、短期纯债 |

### C2 — 稳健型
| 维度 | 典型特征 |
|------|---------|
| 风险承受意愿 | 接受小幅波动 |
| 投资目标 | 保值基础上追求适度增值 |
| 权益类区间 | 5-20% |
| 固收类区间 | 50-85% |
| 货币类区间 | 0-20% |
| 年化波动率范围 | 3-6% |
| 预期最大回撤 | 3-8% |
| 典型产品 | 纯债基金、固收+、银行R2理财 |

### C3 — 平衡型
| 维度 | 典型特征 |
|------|---------|
| 风险承受意愿 | 接受中等波动 |
| 投资目标 | 资本稳健增长 |
| 权益类区间 | 20-50% |
| 固收类区间 | 40-70% |
| 货币类区间 | 0-15% |
| 年化波动率范围 | 6-12% |
| 预期最大回撤 | 8-18% |
| 典型产品 | 混合基金（偏债/平衡）、指数基金 |

### C4 — 积极型
| 维度 | 典型特征 |
|------|---------|
| 风险承受意愿 | 接受较大波动 |
| 投资目标 | 长期资本增值 |
| 权益类区间 | 50-80% |
| 固收类区间 | 10-40% |
| 货币类区间 | 0-10% |
| 年化波动率范围 | 12-20% |
| 预期最大回撤 | 18-30% |
| 典型产品 | 股票基金、指数基金、私募基金 |

### C5 — 激进型
| 维度 | 典型特征 |
|------|---------|
| 风险承受意愿 | 接受剧烈波动，追求高收益 |
| 投资目标 | 最大化资本增值 |
| 权益类区间 | 80-100% |
| 固收类区间 | 0-20% |
| 货币类区间 | 0-10% |
| 年化波动率范围 | 18-30%+ |
| 预期最大回撤 | 25-50%+ |
| 典型产品 | 全权益组合、衍生品、杠杆型 |

## 偏离度诊断方法

### 诊断维度
1. **资产类别偏离**：组合中权益/固收/货币/其他的实际占比 vs 该等级典型区间
2. **波动率偏离**：组合实际/隐含波动率 vs 该等级波动率范围
3. **回撤偏离**：组合历史/预期最大回撤 vs 该等级回撤范围
4. **集中度偏离**：个股/行业集中度是否合理
5. **流动性偏离**：组合中封闭式/定开类占比是否影响流动性需求

### 偏离度分级
| 等级 | 含义 | 示例 |
|------|------|------|
| 匹配 | 各维度在典型区间内 | "你的组合权益类占比 35%，落在平衡型的典型区间 20-50% 内" |
| 轻度偏离 | 个别维度略有超出 | "你的组合波动率 13%，略高于平衡型上限 12%" |
| 显著偏离 | 多维度明显超出 | "你的组合权益类占比 85%，远高于稳健型的典型区间 5-20%" |

## 输出格式规范（合规关键）

### 允许的诊断输出
```
## 风险匹配度诊断

### 你声明的风险偏好: 稳健型 (C2)

### 诊断结果: 显著偏离

你的投资组合实际特征与稳健型存在以下差异：

**资产配置偏离**
- 权益类实际占比 X%，远高于稳健型典型区间 5-20%
- 固收类实际占比 X%，低于稳健型典型区间 50-85%

**风险指标偏离**
- 组合年化波动率 X%，高于稳健型上限 6%
- 最大回撤 X%，高于稳健型上限 8%

**集中度特征**
- 前三大持仓占比 X%，集中度偏高
- 行业集中度：XX 行业占比 X%

### 方向性提示
- 当前组合的波动和回撤水平高于你声明的稳健型通常可承受的范围
- 收益弹性也相应更高

⚠️ 免责声明：以上诊断为风险特征描述性分析，仅供参考，不构成任何投资建议。
本诊断不提供调仓方案或投资推荐。投资有风险，决策需谨慎。
```

### 绝对禁止
- "建议将权益占比从 85% 调整至 30%"（仓位建议）
- "建议买入 XX 债券基金来降低波动"（具体标的推荐）
- "建议在当前时点减仓股票"（买卖时点建议）

## 分析流程

1. 用户提供投资组合 + 声明的风险偏好等级
2. 计算组合的实际资产配置比例
3. 计算组合的实际风险指标（波动率、回撤等）
4. 与声明等级的标准区间逐一对比
5. 计算综合偏离度评分
6. 输出诊断报告（仅描述性 + 方向性提示）

## 合规边界
- [ ] 不包含具体标的推荐
- [ ] 不包含买卖时点建议
- [ ] 不包含仓位配置建议（不输出调仓方案）
- [ ] 所有分析结果附带免责声明
- [ ] 不要求用户提供证券账户信息
