# 历史回撤分析与压力测试

> 本 skill 分析投资组合的历史回撤特征，并应用 A 股历史极端事件进行压力测试。
> 压力测试不是预测未来，而是帮助理解组合在市场极端情况下的脆弱性。

## 概述

分析组合的回撤特征（深度、持续时间、恢复时间、频率），并使用中国 A 股历次重大市场调整事件及因子冲击进行情景压力测试。

## 回撤分析指标体系

### 回撤深度
| 指标 | 计算 | 意义 |
|------|------|------|
| 最大回撤 (MDD) | max((P_t - P_peak) / P_peak) | 组合最极端的峰谷跌幅 |
| 前 3 大回撤 | 历史前 3 深的回撤事件 | 多事件验证回撤模式的稳定性 |
| 平均回撤 | 所有 > 5% 回撤的平均深度 | 常规风险水平 |
| 回撤频率 | >5% / >10% / >20% 回撤次数/年 | 回撤发生密度 |

### 回撤持续性
| 指标 | 计算 | 意义 |
|------|------|------|
| 峰谷时长 | 峰值→谷值的天数 | 下跌速度——急跌 vs 阴跌 |
| 恢复时长 | 谷值→回到前高的天数 | 反弹能力——V 型 vs L 型 |
| 恢复比率 | 恢复天数/峰谷天数 | < 1 → 快跌快涨、> 2 → 慢涨慢跌 |
| 水下总时长 | 低于前高的总天数占比 | 组合"不赚钱"的时间比例 |

### 回撤深度-恢复时间关系
```
浅回撤 (< 10%) 恢复时间: 通常 < 3 个月（中国市场）
中等回撤 (10-20%) 恢复时间: 3-12 个月
深回撤 (> 20%) 恢复时间: 12-24 个月+
```
> 如果组合回撤深度不深但恢复时间极长 → "温水煮青蛙"型风险

### 与基准对比
| 对比指标 | 含义 |
|---------|------|
| 回撤深度 vs 基准 | 深度更大的回撤=组合风控弱于市场 |
| 回撤同步性 | 组合回撤是否与市场回撤同步（市场跌→组合也跌=正常；市场不跌→组合跌=异常） |
| 反弹参与率 | 市场反弹时组合是否跟涨（跟涨=正常，不跟=持仓结构有问题） |

## A 股历史极端事件库

### 事件 1: 2015 年股灾（杠杆牛崩盘）
| 维度 | 数据 |
|------|------|
| 时间 | 2015.06.12 - 2015.08.26（约 55 个交易日） |
| 沪深 300 跌幅 | 约 -45% |
| 创业板指跌幅 | 约 -55% |
| 中证 1000 跌幅 | 约 -55% |
| 关键特征 | 杠杆被动平仓→流动性危机、千股跌停连续发生、国家队万亿入市 |
| 银行/保险跌幅 | 约 -20~30%（金融板块相对抗跌） |
| 修复时间 | 沪深 300 约 2.5 年（至 2018 年 1 月才创新高） |
| 组合测试关注点 | 高 Beta 持仓跌幅远超市场、跌停板流动性锁定→无法止损 |

### 事件 2: 2016 年熔断（流动性恐慌）
| 维度 | 数据 |
|------|------|
| 时间 | 2016.01.04 - 2016.01.28（约 18 个交易日） |
| 沪深 300 跌幅 | 约 -21%（含两天熔断停市） |
| 关键特征 | 熔断机制触发后恐慌加剧、流动性完全枯竭 |
| 组合测试关注点 | 极速下跌中 VaR 模型完全失效（统计模型无法预测政策事件） |

### 事件 3: 2018 年全年阴跌（中美贸易战+去杠杆）
| 维度 | 数据 |
|------|------|
| 时间 | 2018.01.24 - 2019.01.04（约 11 个月） |
| 沪深 300 跌幅 | 约 -32% |
| 特征 | 持续阴跌而非急跌、波动率不高但时间长、几乎无反弹 |
| 强势板块 | 食品饮料(-22%，跑赢)、银行(-15%)、公用事业(-18%) |
| 弱势板块 | 电子(-42%)、传媒(-40%)、有色(-39%) |
| 修复时间 | 约 3 个月（2019 年 Q1 大幅反弹） |
| 组合测试关注点 | 持续亏损的心理折磨、定投策略此期间"越跌越买"考验 |

### 事件 4: 2020 年疫情冲击（V 型暴跌暴涨）
| 维度 | 数据 |
|------|------|
| 时间 | 节前恐慌 2020.01.14 - 2020.02.03（节后首日暴跌） |
| 沪指单日跌幅 | -7.7%（2020.02.03，近 3000 只跌停） |
| 从谷底反弹 | 约 2 周基本修复、约 1 个月超越前高 |
| 后续走势 | 全球流动性宽松 → 大涨至 2021.02（创业板指翻倍） |
| 特征 | V 型极速反转——反应慢的投资者踏空 |
| 组合测试关注点 | 暴跌日恐慌卖出→错失后续大涨（行为风险 > 市场风险） |

### 事件 5: 2021 春节后核心资产崩盘（抱团瓦解）
| 维度 | 数据 |
|------|------|
| 时间 | 2021.02.18 - 2021.03.09（约 14 个交易日） |
| 沪深 300 跌幅 | 约 -15%（快速调整） |
| 抱团股跌幅 | 贵州茅台 -25%、美的集团 -24%、恒瑞医药 -22% |
| 中小盘同期表现 | 中证 500 -7%、国证 2000 甚至微涨 |
| 特征 | 大盘核心资产暴跌，中小盘几乎不受影响 |
| 组合测试关注点 | 风格集中的风险——"核心资产"集中组合暴跌而市场整体没崩 |

### 事件 6: 2022 年两波调整（多重冲击）
| 维度 | 第一波 (2021.12-2022.04) | 第二波 (2022.07-2022.10) |
|------|------------------------|------------------------|
| 沪深 300 跌幅 | -22% | -22% |
| 驱动因素 | 地产危机+疫情封控+中概退市恐慌 | 断供潮+人民币贬值+二十大 |
| 恒生科技跌幅 | -45% | -35% |
| 最抗跌 | 煤炭(+20%)、银行(-5%) | 煤炭(-2%)、交通运输(-8%) |
| 特征 | 多重利空叠加 | 信心极度脆弱 |

### 事件 7: 2024 年初小盘流动性危机
| 维度 | 数据 |
|------|------|
| 时间 | 2024.01.02 - 2024.02.05 |
| 特征 | 雪球产品集中敲入+量化 DMA 策略清盘+两融平仓→小盘流动性踩踏 |
| 沪深 300 跌幅 | 约 -7%（相对温和） |
| 中证 2000 跌幅 | 约 -28%（极度分化） |
| 微盘股指数跌幅 | 约 -40% |
| 修复 | 国家队入场救市 + 2 月 V 型反弹 |
| 组合测试关注点 | 大小盘极端分化——看大盘指数判断组合风险完全不够 |

## 压力测试方法

### 1. 历史情景法（最直观）
将组合在历史极端事件中的表现进行回测：
```
事件压力损失 = Σ(持仓权重_i × 持仓_i 在该事件期间的总回报)
```
- 对无历史数据的持仓，用同类资产指数替代
- 基金持仓：用基金在该事件期间的实际回报
- 分析各事件下组合的脆弱点

### 2. 因子冲击法（最灵活）
对组合的因子暴露施加标准化冲击：

**权益冲击**：
| 冲击类型 | 幅度 | 说明 |
|---------|------|------|
| 股市系统性下跌 | -10%/-20%/-30%/-40% | 对应不同级别的熊市 |
| A股 vs 港股分化 | A股-10%+港股-20% | 如 2022 年情景 |
| 大小盘分化 | 大盘-10%+小盘-30% | 如 2024 年初情景 |
| 价值/成长分化 | 成长-15%+价值-5% | 如 2021 春节后 |
| 特定行业冲击 | 行业指数 -30%/-50% | 如政策冲击 |

**固收冲击**：
| 冲击类型 | 幅度 |
|---------|------|
| 利率上行（平行移动） | +50bp/+100bp/+200bp（整个曲线） |
| 利率陡峭化 | 短端 +50bp + 长端 +100bp |
| 信用利差走阔 | +50bp/+100bp/+200bp（按评级分别） |
| 信用事件 | 高收益债 -5%/-10% |

**多资产联合冲击**：
| 情景 | 股市 | 利率 | 信用 | 汇率 |
|------|------|------|------|------|
| 典型衰退 | -30% | -100bp | +150bp | 人民币 -5% |
| 滞胀 | -20% | +100bp | +100bp | — |
| 流动性危机 | -20% | -50bp(短端) | +200bp | — |
| 强势美元 | -10%(A股) | +50bp | +50bp | 人民币 -10% |

### 3. 相关性压力法
```
正常时期: ρ_avg = 0.3-0.5
危机时期: ρ_avg → 0.7-0.9（"一切皆跌"——分散化失效）
```
测试方法：
- 将组合中所有风险资产的相关系数同时上调 0.3
- 重新计算组合 VaR 和 CVaR
- 对比正常相关性和压力相关性下的组合风险差异

### 4. 流动性压力
| 持仓类型 | 流动性压力假设 |
|---------|-------------|
| A 股大盘 | T+1 可卖出，冲击成本 0.1-0.3% |
| A 股小盘(日均 < 1000 万) | 需要 3-5 天出清，冲击成本 2-5% |
| 封闭式基金 | 封闭期内完全无法变现 |
| 定开类理财 | 仅开放日可赎回 |
| 私募基金 | 通常月度/季度开放，甚至需要提前预约 |

计算组合的**流动性覆盖比**：
```
流动性覆盖率 = 7 天内可变现资产 / 7 天内的刚性支出
< 1 → 流动性缺口，极端情况下需折价变现
```

## 压力测试局限性（必须说明）

| 局限 | 说明 |
|------|------|
| 历史不一定重演 | 下一次危机可能以完全不同的形式出现 |
| 相关性在危机中不稳定 | 分散化在极端事件中大概率失效 |
| 模型假设可能被突破 | 正态分布假设、流动性假设在极端事件中不成立 |
| 新风险未被历史捕获 | 如雪球产品风险在 2024 年之前不存在 |
| 行为风险无法量化 | 投资者在极端事件中的恐慌性操作是最大的变量 |

## 分析流程

1. 获取组合历史净值数据（或按当前持仓构建代理组合回测）
2. 计算回撤指标（MDD、前 3 大回撤、恢复时间、水下占比等）
3. 与市场基准（沪深 300/中证全指）对比回撤特征
4. 选择用户关注的压力情景（历史情景 + 因子冲击）
5. 逐一模拟各情景下的潜在损失
6. 执行相关性压力测试（协方差矩阵扰动）
7. 执行流动性压力测试
8. 综合评估组合的抗压能力和脆弱点
9. 输出压力测试报告（附带局限性声明）
