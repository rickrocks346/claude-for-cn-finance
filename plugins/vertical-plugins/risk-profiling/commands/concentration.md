# /concentration [投资组合]

## 输入
- `投资组合`（必需）：持仓列表（股票/基金/ETF 代码及权重）
- 可选参数：`--depth=penetrate`（穿透基金持仓）、`--threshold=20%`（预警阈值）

## 流程
1. 获取各持仓基本信息（行业/市值/风格/地域）
2. 按个股维度计算 CR1/CR3/CR5/CR10/HHI/Effective N
3. 按申万一级行业汇总行业权重
4. 按市值风格、价值/成长风格、地域分别汇总
5. 基金组合执行穿透分析
6. 识别所有超过预警阈值的维度

## 输出
- 个股集中度面板（CRn + HHI + 等效持仓数）
- 行业/市值/风格/地域分布表
- 多维度集中度仪表盘（红/黄/绿灯）
- 基金穿透分析（如适用）
- 伪分散风险提示
