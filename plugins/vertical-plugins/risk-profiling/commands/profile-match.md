# /cn-finance:profile-match [风险等级]

## 输入
- `风险等级`（必需）：C1(保守)/C2(稳健)/C3(平衡)/C4(积极)/C5(激进)
- 用户上传的投资组合（当前对话中的 Excel/CSV 或手动输入）
- 可选参数：`--output=summary|full`（输出详细度）

## 流程
1. 读取用户声明的风险偏好等级
2. 读取用户上传的组合数据
3. 计算组合的实际资产配置比例
4. 计算组合的实际风险指标
5. 与标准区间逐一对比
6. 识别所有偏离维度及偏离程度
7. 输出匹配度诊断报告

## 输出
- 风险偏好等级标准（供对照）
- 组合实际特征 vs 标准区间对比表
- 各维度偏离判断（匹配/轻度偏离/显著偏离）
- 方向性风险提示（仅描述，不调仓）

## 重要约束
本命令只做描述性诊断，不提供调仓建议。例如：
- ✓ "你的组合权益类占比 85%，远高于稳健型的典型区间 5-20%"
- ✗ "建议你将权益占比降低到 20%"
- ✗ "建议买入 XX 债券基金来降低波动"

⚠️ 免责声明：以上诊断为风险特征描述性分析，仅供参考，不构成任何投资建议。本诊断不提供调仓方案或投资推荐。投资有风险，决策需谨慎。请咨询持牌专业人士。

## 合规边界
- 不包含具体标的推荐
- 不包含买卖时点建议
- 不包含仓位配置建议（不输出调仓方案）
- 输出末尾附带 disclaimer
- 不要求提供证券账户信息
