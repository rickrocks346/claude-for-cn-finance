# /cn-finance:one-pager [股票代码]

## 输入
- `股票代码`（必需）：6 位数字代码
- 可选参数：`--with-peers`（附带行业排名信息）

## 流程
1. 获取公司基本信息（全称、行业、上市日期、实际控制人）
2. 获取近 3 年核心财务数据
3. 获取当前估值和行情数据
4. 获取前十大股东和质押信息
5. 如指定 `--with-peers`：计算行业排名
6. 按一页纸模板格式化输出

## 输出
- 公司概况
- 核心财务（3 年趋势表）
- 估值与市场表现（PE/PB 当前值 + 历史分位）
- 股权结构（控股股东、质押、减持动态）
- 行业地位（排名、优势、主要竞争对手）
