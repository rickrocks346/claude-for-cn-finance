# 政策影响分析

> 中国 A 股市场具有显著的政策驱动特征。本 skill 提供政策分析的框架，帮助理解政策对市场和行业的影响路径。

## 概述

分析中国财政政策、货币政策、产业政策、监管政策对 A 股市场的影响。不做政策方向预测，只做已有政策的传导路径分析。

## 中国政策框架

### 财政政策
| 工具 | 传导机制 | 影响行业 |
|------|---------|---------|
| 赤字率 | 政府支出规模 → 总需求 | 基建、建材、工程机械 |
| 专项债 | 地方基建投资 → 产业链拉动 | 建筑、钢铁、水泥 |
| 减税降费 | 企业利润改善 → 投资+就业 | 制造业、中小微 |
| 财政补贴 | 消费/生产刺激 → 量增 | 新能源车、光伏、家电 |

### 货币政策
| 工具 | 传导机制 | 影响行业 |
|------|---------|---------|
| 降准 | 银行可贷资金增加 → 信贷宽松 | 银行（量增）、地产 |
| 降息（MLF/LPR） | 融资成本下降 → 投资/消费 | 地产、可选消费、制造业 |
| 公开市场操作 | 短期流动性管理 → 资金利率 | 债券市场、券商 |
| PSL/结构性工具 | 定向流动性支持 → 特定领域 | 棚改→地产、科技再贷款→半导体 |

### 产业政策
| 政策类型 | 典型文件 | 影响方式 |
|---------|---------|---------|
| 五年规划 | 十四五/十五五规划 | 顶层设计，方向性指引 |
| 产业振兴计划 | 新能源汽车产业发展规划 | 补贴+配套+准入 |
| 国产替代 | 信创/半导体/高端装备 | 政府采购+投资驱动 |
| 行业监管 | 反垄断/集采/双减 | 限制性，改变行业格局 |

## 政策传导路径分析框架

### 四层传导
1. **政策层**：文件发布 → 政策基调确认
2. **执行层**：部门/地方配套细则 → 执行时间表
3. **基本面层**：行业订单/收入/利润变化
4. **市场层**：估值变化 → 资金流向变化

### 政策影响等级
| 等级 | 特征 | 市场反应 |
|------|------|---------|
| 顶层设计 | 中央/国务院级别文件 | 长期方向性影响 |
| 具体落地 | 部委/地方配套细则 | 中期行业格局变化 |
| 窗口指导 | 监管约谈/问询 | 短期情绪/资金面 |
| 市场传闻 | 未经证实的消息 | 短期炒作/波动 |

## 历史政策案例库格式

用于研究的案例模板（每次分析时按此结构整理）：

```
### 案例：{政策名称} ({发布时间})
**政策级别**: [顶层设计 / 具体落地 / 窗口指导]
**涉及行业**: [受益 / 受损]
**关键条款**: ...
**短期市场反应**: ...
**中期行业影响**: ...
**相关数据参考**: ...
```

## 分析流程

1. 确定分析的政策事件
2. 分类：财政/货币/产业/监管
3. 分析传导路径和影响链条
4. 参考历史相似政策案例
5. 标注影响等级和确定性
