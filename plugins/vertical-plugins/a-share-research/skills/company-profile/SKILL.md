# A股公司一页纸速览

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取公司信息、行情和财务数据。

## 概述

生成 A 股上市公司的标准化一页纸速览报告，覆盖公司概况、股权结构、核心财务、估值水平和行业地位。

## 速览模板结构

### 1. 公司概况
- 公司全称和简称
- 股票代码（含交易所）
- 上市日期
- 所属行业（申万一级/二级/三级）
- 实际控制人/控股股东
- 主营业务描述（一句话）

### 2. 股权结构
- 控股股东及持股比例
- 前十大股东及其性质（国有/民营/外资/机构）
- 股权质押比例（控股股东）
- 是否有减持计划（近半年）

### 3. 核心财务（近 3 年）
- 营业收入及增速
- 归母净利润及增速
- 扣非净利润
- ROE / ROA
- 毛利率 / 净利率
- 资产负债率
- 经营现金流净额

### 4. 估值水平
- PE (TTM) 及历史分位
- PB 及历史分位
- 总市值
- 流通市值
- 近 1 年/3 年涨跌幅

### 5. 行业地位
- 细分行业排名（按市值/收入/利润）
- 市场份额估算
- 核心竞争优势
- 主要竞争对手（2-3 家）

## 分析流程

1. 输入股票代码
2. 获取公司基本信息（代码、名称、行业、上市日期）
3. 获取财务数据（近 3-5 年核心指标）
4. 获取行情数据（当前估值、涨跌幅）
5. 获取股东信息
6. 按模板格式化输出

## 输出格式

```
# {公司简称} ({股票代码}) — 一页纸速览

## 公司概况
- 全称: ...
- 行业: 申万{一级}/{二级}
- 上市日期: ...
- 实际控制人: ...

## 核心财务
| 指标 | {Y-2} | {Y-1} | {Y0} | 3Y趋势 |
|------|-------|-------|------|--------|
| 营业收入(亿) | ... | ... | ... | ... |
| 归母净利润(亿) | ... | ... | ... | ... |
| ROE | ... | ... | ... | ... |

## 估值与市场表现
- PE (TTM): ... (近5年 X% 分位)
- PB: ... (近5年 X% 分位)
- 总市值: ... | 流通市值: ...

## 股权与治理
- 控股股东: ... (持股 X%)
- 前十大持股: X% | 质押: X%

## 行业地位
- 行业排名: 市值第 X / 收入第 X (共 Y 家)
- 核心优势: ...
```
