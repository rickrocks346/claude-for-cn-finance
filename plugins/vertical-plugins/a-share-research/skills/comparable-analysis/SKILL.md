# A股可比公司分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取行情和财务数据。

## 概述

基于申万/中信行业分类体系，在中国 A 股市场筛选可比公司，进行多维度的估值与经营指标对比。

## 可比公司选取方法

### 筛选标准
1. **行业相同**：同一申万三级或四级行业
2. **规模相近**：市值在目标公司的 0.3x - 3x 范围
3. **业务相似**：主营业务结构可比
4. **上市时间**：> 1 年以消除新股效应
5. **排除 ST/退市风险警示**：排除非正常经营状态公司

### 选取数量
- 理想区间：5-15 家
- 太少 → 分位统计不稳健
- 太多 → 需要进一步细分筛选

## A股常用估值倍数

| 倍数 | 适用行业 | A股注意事项 |
|------|---------|-----------|
| PE (TTM) | 盈利稳定行业（消费、金融） | 扣非 PE 更可靠 |
| PB | 金融（银行/保险/券商）、周期股 | A股 PB 中枢高于成熟市场 |
| PS | 成长型/亏损公司（互联网、生物医药） | A股 SaaS 公司较少 |
| EV-EBITDA | 制造业、重资产 | 剔除折旧政策差异 |
| PEG | 成长股 | A股高增长期 PEG 容忍度更高 |
| PCF | 现金流充沛行业 | 经营现金流更可靠 |

## 历史分位数分析

### 数据范围
- 建议使用 3-5 年历史数据
- 覆盖一个完整牛熊周期更理想

### 分位数解读框架
| 分位 | 含义 |
|------|------|
| < 20% | 当前估值处于历史低位 |
| 20-40% | 当前估值处于历史中低位 |
| 40-60% | 当前估值处于历史中位 |
| 60-80% | 当前估值处于历史中高位 |
| > 80% | 当前估值处于历史高位 |

## 分析流程

1. 确定目标公司所在行业
2. 按筛选标准选出可比公司列表
3. 获取估值倍数和财务指标
4. 计算行业中位数和各分位数
5. 对比目标公司在可比组中的位置
6. 结合历史分位数分析
7. 输出比较报告
