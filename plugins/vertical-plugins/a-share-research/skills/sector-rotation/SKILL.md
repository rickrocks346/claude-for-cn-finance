# A股板块轮动分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取行业板块数据。

## 概述

基于申万/中信行业分类体系，分析 A 股行业板块的轮动特征、涨跌规律和驱动因素。

## A股行业分类（申万 2021 版一级行业）

| 板块 | 行业 | 典型驱动因素 |
|------|------|------------|
| 周期 | 煤炭、石油石化、钢铁、有色、化工、建筑材料 | 大宗商品价格、PPI、基建 |
| 制造 | 电力设备、机械设备、国防军工、汽车 | 产业政策、出口、技术迭代 |
| 消费 | 食品饮料、家用电器、纺织服饰、商贸零售、社服 | 居民收入、消费信心、CPI |
| 医药 | 医药生物 | 集采政策、研发管线、老龄化 |
| TMT | 电子、计算机、通信、传媒 | 技术周期、AI、政策（国产替代） |
| 金融 | 银行、非银金融、房地产 | 利率、息差、地产政策 |
| 公用事业 | 公用事业、交通运输、环保 | 电价/运价、新能源政策 |

## A股板块轮动规律

### 经济周期框架
| 阶段 | 强势板块 | 弱势板块 | A股特征 |
|------|---------|---------|--------|
| 复苏 | 周期（有色/化工/机械）、可选消费 | 债券型、防御型 | 政策驱动强于市场自发 |
| 过热 | 资源（煤炭/钢铁）、金融（银行） | 债券 | 一般较短 |
| 滞胀 | 能源（石油石化）、公用事业 | 高估值成长 | A股此阶段较少见 |
| 衰退 | 消费（食品饮料/医药）、公用事业 | 周期、金融 | 政策对冲下"防御"弱于海外 |

### 日历效应
| 时段 | 关注点 | A股特征 |
|------|--------|--------|
| 1-2 月 | 年报预告、春季躁动 | 小盘成长股活跃 |
| 3-4 月 | 年报披露、两会行情 | 政策主题活跃 |
| 5-6 月 | 业绩真空期 | 主题炒作、炒地图 |
| 7-8 月 | 中报披露 | 业绩为王、分化加大 |
| 9-10 月 | 三季报 | 三季报决定全年预期 |
| 11-12 月 | 年底结账 | 公募排名、落袋为安 |

## 政策与板块关联性

| 政策方向 | 最受益板块 | 传导路径 |
|---------|-----------|---------|
| 降准/降息 | 金融（银行息差除外）、地产 | 降低融资成本 → 提升估值 |
| 基建投资 | 建筑、建材、工程机械、水泥 | 专项债 → 基建项目 → 订单 |
| 新能源补贴 | 光伏、风电、储能、锂电 | 补贴 → 装机 → 出货 |
| 芯片国产替代 | 半导体、设备 | 政策+资金 → 设计/制造/封测 |
| 消费刺激 | 汽车、家电、社服 | 补贴/减税 → 消费意愿 |
| 地产放松 | 地产、建材、家居、银行 | 限购放松 → 销售改善 → 投资 |
| 集采 | 仿制药 → 利空 / 创新药 → 中性偏多 | 量增价降 vs 创新溢价 |

## 分析流程

1. 获取申万一级行业指数近 1-3 年行情
2. 计算各行业涨跌幅排名和换手率
3. 计算行业间的相关性矩阵
4. 结合宏观经济指标判断当前周期位置
5. 分析近期政策对行业的影响方向
6. 输出板块轮动分析
