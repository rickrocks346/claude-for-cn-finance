# A股板块轮动分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取行业板块数据。

## 概述

基于申万/中信行业分类体系，分析 A 股行业板块的轮动特征、涨跌规律和驱动因素。

## A股行业分类（申万 2021 版一级行业 31 个）

| 板块 | 行业 | 典型驱动因素 |
|------|------|------------|
| 周期 | 煤炭、石油石化、钢铁、有色、化工、建筑材料 | 大宗商品价格、PPI、基建 |
| 制造 | 电力设备、机械设备、国防军工、汽车、轻工制造 | 产业政策、出口、技术迭代 |

| TMT | 电子、计算机、通信、传媒 | 技术周期、AI、政策（国产替代） |

## 板块轮动定量分析框架

### 相对强弱分析（RS）
```
行业 RS = 行业指数涨幅 - 基准指数（沪深300）涨幅（滚动 N 日）
RS 动量 = RS 的 N 日移动平均
RS > 0 且上行 → 相对强势（关注）
RS > 0 但下行 → 强势减弱（可能转向）
RS < 0 但上行 → 弱势改善（可能反转）
RS < 0 且下行 → 相对弱势（回避）
```

### 行业宽度指标
| 指标 | 计算 | 信号 |
|------|------|------|
| 行业内上涨股票占比 | 行业内上涨家数 / 行业总家数 | > 60% 行业普涨，< 30% 普跌 |
| 行业内站上 20 日均线比例 | 收盘价 > MA20 的家数占比 | > 60% 趋势向上，< 30% 趋势向下 |
| 行业内创新高股票数 | N 日内创 N 日新高的家数 | 大幅增加 → 资金加速进入 |

### 资金流向分析
| 资金类型 | 数据来源 | 分析要点 |
|---------|---------|---------|
| 北向资金（陆股通） | 沪深港通每日披露 | 行业净买入/卖出，持续流入行业 |
| 融资融券 | 两融余额变化 | 行业融资买入额/融资余额变化 |
| ETF 资金 | 行业 ETF 份额变化 | 个人+机构通过 ETF 配置方向 |
| 主力资金 | 大单/超大单净流入 | Wind/同花顺大单统计（短期指标，噪音大） |
| 公募基金重仓 | 季报披露（滞后约1个月） | 前十大重仓行业配置变化 |

### 行业拥挤度
```
拥挤度 = 行业成交额占比 / 行业流通市值占比
> 1.5 → 交易拥挤，短期风险上升
0.5-1.5 → 正常区间
< 0.5 → 关注度低，可能冷门反转
```

## 经济周期框架下板块轮动

| 阶段 | 强势板块 | 弱势板块 | A股特征 |
|------|---------|---------|--------|
| 复苏早期 | 可选消费（汽车/家电）、TMT（电子/计算机） | 防御型（公用事业） | 政策驱动强于市场自发 |
| 复苏中期 | 周期（有色/化工/机械）、金融（券商） | 债券型 | 工业利润改善传导至投资 |
| 过热 | 资源（煤炭/钢铁）、金融（银行） | 高估值成长 | A股此阶段通常较短（政策主动降温） |
| 滞胀 | 能源（石油石化）、公用事业 | 高估值成长、可选消费 | A股此阶段较少见但 2021-2022 典型 |
| 衰退早期 | 消费（食品饮料/医药）、公用事业 | 周期、金融 | 政策对冲下"防御"弱于海外 |
| 衰退后期 | 金融（券商/银行）、周期龙头 | 小盘股 | 政策宽松预期升温，提前交易复苏 |

### A股周期判断核心指标
| 指标 | 信号 | 数据来源 |
|------|------|---------|
| PMI 连续 3 个月 > 50 | 经济扩张确认 | 国家统计局 |
| 社融增速触底回升 | 信用扩张，领先经济 1-2Q | 人民银行 |
| PPI 触底回升 | 企业盈利改善，周期股先行 | 国家统计局 |
| 工业企业利润增速转正 | 企业盈利底部确认 | 国家统计局 |
| M1-M2 剪刀差收窄 | 资金活化程度改善 | 人民银行 |
| 10Y 国债收益率上行 | 经济预期改善 | 中国债券信息网 |

## A股特有的风格轮动

### 大小盘轮动
| 阶段 | 大盘风格占优条件 | 小盘风格占优条件 |
|------|---------------|---------------|
| 经济下行/不确定性高 | 确定性溢价 → 大盘 | — |
| 流动性宽松 | — | 资金成本低 → 小盘题材活跃 |
| 经济复苏 | 盈利确定性 → 大盘 | — |
| 政策/题材驱动 | — | 科创板/专精特新 → 小盘 |
| 外资流入 | 沪深 300 权重 → 大盘 | — |

### 价值 vs 成长轮动
| 条件 | 有利于 |
|------|--------|
| 利率上行 | 价值（高股息替代债券） |
| 利率下行 | 成长（远期现金流折现价值上升） |
| 经济复苏确认 | 价值（盈利改善确定） |
| 新技术/产业趋势爆发 | 成长（想象空间打开） |
| 市场风险偏好低 | 价值（防御属性） |

### A股风格轮动关键信号
| 信号 | 含义 |
|------|------|
| 红利指数/创业板指 比值上升 | 价值风格占优 |
| 国证 2000/沪深 300 比值上升 | 小盘风格占优 |
| 微盘股指数暴涨暴跌 | 投机情绪极端化 |
| 券商板块异动 | 往往是市场转向的先行指标 |

## 日历效应（A股季节性规律）

| 时段 | 关注点 | A股典型表现 | 原因 |
|------|--------|-----------|------|
| 1-2 月 | 春季躁动、年报预告 | 小盘成长/科技活跃 | 流动性宽松+政策预期+业绩真空期 |
| 3 月 | 两会行情 | 政策主题（新质生产力/碳中和/数字经济） | 两会窗口期 |
| 4 月 | 年报+一季报 | 业绩确定性强的板块 | 业绩验证期，炒概念退潮 |
| 5-6 月 | 业绩真空期 | 主题炒作活跃 | 缺乏基本面锚定 |
| 7-8 月 | 中报披露 | 业绩分化加大 | 中报是全年最完整的中期验证 |
| 9-10 月 | 三季报+国庆 | 消费/旅游国庆前活跃 | 三季报锁定全年预期 |
| 11-12 月 | 年底排名 | 公募重仓股异动 | 排名争夺+落袋为安+高低切换 |

## 政策与板块关联性

| 政策方向 | 最受益板块 | 可能受损板块 | 传导路径 |
|---------|-----------|------------|---------|
| 降准/降息 | 券商、地产、建材 | 银行（息差收窄） | 融资成本下降 → 估值提升 |
| 扩大财政赤字 | 基建、建筑、水泥、工程机械 | — | 专项债 → 项目 → 订单 → 业绩 |
| 新能源政策 | 光伏、风电、储能、锂电 | 传统火电 | 补贴/装机目标 → 出货量 |
| 芯片国产替代 | 半导体设备/材料/设计 | — | 大基金+政策 → 资本开支 |
| 消费刺激 | 汽车、家电、餐饮旅游 | — | 补贴/消费券 → 销量 |
| 地产放松 | 地产、建材、家居、银行 | — | 限购放松 → 销售 → 投资链 |
| 集采扩面 | 创新药/器械（长期） | 仿制药/高值耗材 | 量增价降 vs 创新溢价 |
| 数据要素/数字经济 | 计算机、通信、传媒 | — | 政策定调 → 投资 → 订单 |

## 行业轮动量化信号清单

### 动量类
- 近 5/10/20/60 日涨跌幅排名
- 相对沪深 300 超额收益趋势
- 创新高/新低的行业数量

### 资金类
- 北向资金行业净买卖（持续 5 日以上方向）
- 行业 ETF 份额周度变化
- 融资余额周度变化

### 基本面类
- PMI 及分项（新订单、新出口订单、购进价格）
- PPI-CPI 剪刀差走势
- 工业企业利润分行业增速

### 情绪/估值类
- 行业 PE/PB 当前历史分位
- 行业成交额占比 vs 市值占比
- 行业换手率相对历史均值

## 分析流程

1. 获取申万一级行业指数近 1-3 年日频行情
2. 计算各行业区间涨跌幅排名和相对强弱
3. 计算行业相关性矩阵（识别集群轮动模式）
4. 分析各行业资金流向（北向/两融/ETF）
5. 结合宏观经济指标判断当前周期位置
6. 计算行业拥挤度和估值分位
7. 分析近期政策对行业的影响方向
8. 识别当前风格偏向（大小盘/价值成长）
9. 输出板块轮动综合分析
