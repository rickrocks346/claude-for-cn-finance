# /wealth [产品名称 或 产品代码]

## 输入
- `产品名称` 或 `产品代码`（必需）
- 可选参数：`--compare=同类均值`（同类产品对比）、`--period=6m|1y|all`（分析期限）

## 流程
1. 获取产品说明书概要（类型、风险等级、费用结构）
2. 获取历史净值数据，计算收益和风险指标
3. 分析费用结构（综合费率 + 超额报酬条款）
4. 获取最新季报，分析大类资产配置
5. 如做比较：同类型多产品横向对比

## 输出
- 产品要素总览（管理人/风险等级/类型/期限/基准）
- 收益表现（近 1/3/6/12 月年化 + 成立以来）
- 风险指标（最大回撤/波动率/负收益天数占比）
- 费用结构明细
- 投资组合分析（底层资产配置）
