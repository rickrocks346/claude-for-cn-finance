# /cn-finance:cb-analysis [可转债代码]

## 输入
- `可转债代码`（必需）：可转债代码
- 可选参数：`--with-bond-floor`（计算纯债价值/债底）
- 可选参数：`--check-clauses`（检查下修/强赎/回售触发状态）

## 流程
1. 获取可转债基本信息（转股价、条款、评级、到期日）
2. 获取正股最新行情
3. 计算转股价值、转股溢价率
4. 如指定 `--with-bond-floor`：计算纯债价值和纯债溢价率
5. 如指定 `--check-clauses`：检查三大条款触发状态
6. 计算到期收益率和平衡点
7. 输出可转债分析报告

## 输出
- 转债 + 正股基本信息
- 核心指标（转股价值、溢价率、YTM、纯债溢价率）
- 条款触发状态（下修/强赎/回售）
- 股性 vs 债性判断
- 平衡点分析
