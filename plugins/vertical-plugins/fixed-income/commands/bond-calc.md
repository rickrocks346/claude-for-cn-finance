# /cn-finance:bond-calc [债券代码]

## 输入
- `债券代码`（必需）：债券代码
- 可选参数：`--type=treasury|policy-bank|corporate|cib|abs`（债券类型）
- 可选参数：`--price=X`（指定结算价，默认取最新净价）

## 流程
1. 获取债券基本信息（发行人、评级、票面利率、到期日等）
2. 计算 YTM、修正久期、凸性
3. 信用债：分析发行人信用状况
4. 比较同期限同评级债券的利差
5. 输出债券分析报告

## 输出
- 债券基本信息表
- 估值核心指标（YTM、久期、凸性）
- 信用利差及分位
- 利率敏感性分析（利率变动 ±50bp 的价格影响）
