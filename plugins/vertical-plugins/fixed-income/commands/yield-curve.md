# /yield-curve

## 输入
- 可选参数：`--type=all|treasury|policy-bank|credit`（曲线类型，默认 all）
- 可选参数：`--credit-rating=AAA|AA+|AA`（信用债评级，默认 AAA）
- 可选参数：`--compare=1m|3m|1y`（与历史曲线比较）
- 可选参数：`--with-spread`（附带信用利差分析）

## 流程
1. 获取最新各期限国债收益率
2. 如指定其他类型：获取对应曲线数据
3. 计算关键利差（10Y-2Y、10Y-1Y）
4. 如指定 `--compare`：与历史曲线变动对比
5. 如指定 `--with-spread`：计算信用利差曲线
6. 输出收益率曲线分析

## 输出
- 各期限即期利率表
- 曲线形态判断（正常/陡峭/平坦/倒挂）
- 关键利差及历史分位
- 与历史曲线变动对比
- 信用利差分析（如指定）
