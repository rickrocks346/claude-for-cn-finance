# 可转债分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取可转债行情和正股数据。

## 概述

分析中国可转债的核心指标和投资特征，包括转股价值、溢价率、到期收益率、下修博弈和强赎逻辑。

## 中国可转债市场特殊规则

| 规则 | 说明 |
|------|------|
| T+0 交易 | 当日买入可当日卖出（股票 T+1） |
| 无涨跌停 | 理论上无涨跌停限制（盘中临停机制） |
| 转股期 | 通常上市 6 个月后进入转股期 |
| 下修条款 | 正股价低于转股价一定比例时，董事会可提议下修 |
| 强赎条款 | 正股价高于转股价 130% 持续一定天数，公司可强制赎回 |
| 回售条款 | 正股价持续低于转股价一定比例，投资者可将转债回售给公司 |

## 核心指标

### 转股价值
```
转股价值 = (100 / 转股价) × 正股价格
```

### 转股溢价率
```
转股溢价率 = (转债价格 - 转股价值) / 转股价值 × 100%
```
- 溢价率越低 → 转债与正股联动越强
- 溢价率越高 → 债性越强，股性越弱
- 溢价率为负 → 折价（可能存在套利，需考虑转股期和流动性）

### 纯债价值（债底）
```
纯债价值 = 按同评级同期限信用债收益率折现的债券现金流现值
```

### 纯债溢价率
```
纯债溢价率 = (转债价格 - 纯债价值) / 纯债价值 × 100%
```
- 衡量转债在纯债价值之上的溢价
- 纯债溢价率越低 → 下行保护越强

### 到期收益率 (YTM)
- 假设持有至到期，按面值+利息计算的年化收益率
- YTM 为正 → 持有到期有利息回报
- YTM 为负 → 价格完全由转股预期支撑

### 平衡点分析
- 正股需要上涨 X% → 转债的转股价值回到当前转债价格
- 衡量当前价格对应的隐含正股涨幅预期

## 条款博弈分析

### 下修博弈
- 下修条件：通常正股价 < 转股价 × 85% 持续 N 日
- 下修意愿：大股东意愿、财务压力、转股稀释比例
- 下修幅度：可能修到正股价附近或净资产以上

### 强赎博弈
- 强赎条件：正股价 > 转股价 × 130% 持续 N 日
- 强赎公告后：转债溢价率快速收敛至 0
- 未转股投资者面临强赎价（面值+利息）vs 转股价值的选择

## 分析流程

1. 获取转债基本信息（转股价、条款、评级）
2. 获取正股最新价格
3. 计算核心指标（转股价值、溢价率、YTM）
4. 判断当前价格主要由股性还是债性驱动
5. 检查下修/强赎/回售触发状态
6. 输出可转债分析报告
