# 可转债分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取可转债行情和正股数据。

## 概述

分析中国可转债的核心指标和投资特征，包括转股价值、溢价率、到期收益率、下修博弈和强赎逻辑。可转债是 A 股市场独特的"进可攻退可守"品种。

## 中国可转债市场特殊规则

| 规则 | 说明 | 影响 |
|------|------|------|
| T+0 交易 | 当日买入可当日卖出（股票 T+1） | 流动性远好于正股 |
| 无涨跌停板 | 理论上无涨跌停（但有盘中临停机制） | 日内波动可能极大 |
| 转股期 | 发行后 6 个月方可转股 | 上市初期 6 个月只有交易价值无转换价值 |
| 下修条款 | 正股价低于转股价一定比例时董事会可提议下修 | 中国特有的"重置"机制 |
| 强赎条款 | 正股价 > 转股价 × 130% 持续一定天数 | 促转股手段，公告后溢价率迅速归零 |
| 回售条款 | 正股价持续低于转股价一定比例，可按面值+利息回售 | 投资者的下行保护 |
| 网上申购 | 信用申购（无需市值），中签后缴款 | 散户参与度高 |
| 面值 | 100 元 | — |

### 盘中临停机制
| 市场 | 临停规则 |
|------|---------|
| 沪市 | 涨跌 ±20% 停牌 30 分钟，±30% 停牌至 14:57 |
| 深市 | 涨跌 ±20% 停牌 30 分钟，±30% 停牌至 14:57 |

## 可转债核心指标

### 1. 转股价值（平价）
```
转股价值 = (100 / 转股价) × 正股价格
```
- 可转债的核心锚——正股价格决定了转股的内在价值
- 转股价值 = 100 → 转债为"平值"（at-the-money）
- 转股价值 > 130 → 进入强赎触发区
- 转股价值 < 70 → 深度虚值，纯债属性主导

### 2. 转股溢价率
```
转股溢价率 = (转债价格 - 转股价值) / 转股价值 × 100%
```
- **这是最重要的定价指标**
- 溢价率反映市场对正股未来上涨的预期以及转债的期权价值
| 溢价率 | 含义 |
|--------|------|
| < 0%（折价） | 转债价格低于内在价值（罕见，通常有转股限制或流动性问题） |
| 0-15% | 偏股型——与正股联动紧密 |
| 15-30% | 平衡型——兼具股性和债性 |
| 30-50% | 偏债型——正股需要大幅上涨才能覆盖溢价 |
| > 50% | 高度偏债——转股价值对转债价格影响很小 |

### 3. 纯债价值（债底）
```
纯债价值 = Σ(每期票息 + 到期赎回价(含补偿利率)) / (1 + 同评级贴现率)^t
```
- 可转债的"保底"价值——即使正股归零，持有到期收回的价值
- 贴现率 = 同期限同评级信用债收益率
- 中国可转债债底通常在 85-98 元（评级越高、剩余期限越短→债底越高）

### 4. 纯债溢价率
```
纯债溢价率 = (转债价格 - 纯债价值) / 纯债价值 × 100%
```
| 纯债溢价率 | 含义 |
|-----------|------|
| < 10% | 下行保护强——即使正股大跌，亏损空间有限 |
| 10-30% | 中等下行保护 |
| 30-50% | 下行保护弱——如果正股大跌，转债也会大跌 |
| > 50% | 几乎没有下行保护——完全是权益属性 |

### 5. 到期收益率 (YTM)
```
以当前转债价格买入，持有至到期（不考虑转股）的 IRR
```
| YTM | 含义 |
|-----|------|
| > 3% | 具有纯债配置价值（持有到期有正回报） |
| 0-3% | 保本但不赚钱 |
| < 0%（负） | 持有到期必然亏损——完全依赖转股赚钱 |

### 6. 隐含波动率
通过转债市价反推的 Black-Scholes 隐含波动率（考虑中国可转债的特殊条款后调整）
- 隐含波动率 > 历史波动率 → 转债偏贵
- 隐含波动率 < 历史波动率 → 转债相对便宜

### 7. Delta / Gamma
| 希腊字母 | 含义 | 典型范围 |
|---------|------|---------|
| Delta | 正股涨 1 元 → 转债涨约 Delta 元 | 偏股型 0.6-1.0、平衡型 0.3-0.6、偏债型 0-0.3 |
| Gamma | Delta 的变化速度（期权曲率） | 平价附近 Gamma 最大 |

### 平衡点（盈亏平衡涨幅）
```
正股需涨幅 = (转债价格 / 转股价值 - 1) × 100%
```
衡量当前价格对应的隐含正股涨幅预期。

## 可转债定价：BS 模型 + 中国特色

### 标准 BS 模型的问题
标准 Black-Scholes 模型假设欧式期权（仅到期行权），但中国可转债是：
- **美式/百慕大式**：转股期内随时可转股
- **有下修条款**：相当于期权行权价可以重置
- **有强赎条款**：相当于向上敲出
- **有回售条款**：相当于向下保护

### 实用的简化定价思维
```
转债价格 ≈ max(纯债价值, 转股价值) + 期权时间价值
          - 强赎风险折价 + 下修可能性溢价
```

**当前价格主要由什么驱动？**
```
股性强度 = |转债涨跌幅| / |正股涨跌幅|（日频）
> 0.7 → 股性主导（溢价率低）
0.3-0.7 → 平衡
< 0.3 → 债性主导（溢价率高）
```

## 条款博弈深度分析

### 下修博弈（中国特色核心）
| 博弈要素 | 分析 |
|---------|------|
| 下修触发条件 | 通常：正股价 < 转股价 × 85% 持续 15/20/30 日中 N 日 |
| 下修动机 | 1) 避免回售压力 2) 促转股减轻债务 3) 大股东配售解禁 |
| 下修意愿判断 | 大股东是否配售转债（利益绑定）/ 财务压力 / PB>1（下修空间） |
| 下修幅度 | 可修至：正股均价/股东大会前一日价/不低于每股净资产 |
| 净资产限制 | 如果 PB < 1（股价低于每股净资产），则转股价最低只能修到净资产 → 下修空间有限 |
| 下修时间窗口 | 每年通常 1 次（董事会提议→股东大会表决→实施） |
| 下修后的投资窗口 | 下修公告至实施日期间是转债价格重估的窗口期 |

### 强赎博弈
| 博弈要素 | 分析 |
|---------|------|
| 强赎触发条件 | 正股价 > 转股价 × 130% 持续 15/20/30 日中 ≥ N 日 |
| 强赎公告效应 | 公告后转债溢价率 → 0（快速收敛），持有人必须转股或卖出 |
| 不强赎 vs 强赎 | 首次满足条件时公司可能公告"本次不强赎"→ 溢价率恢复部分 |
| 强赎前交易策略 | 满足条件但尚未公告期间 → 溢价率逐渐压缩 |
| 强赎价 | 面值 + 当期利息（约 100-103 元），远低于转股价值 |

### 回售博弈
| 博弈要素 | 分析 |
|---------|------|
| 回售触发条件 | 通常最后 2 年、正股价 < 转股价 × 70% 持续 30 日 |
| 回售价 | 面值 + 利息（约 100-103 元） |
| 回售 vs 下修 | 公司通常在回售触发前选择下修转股价以避免回售 |
| 回售是最后防线 | 如果公司既不回售也不下修 → 信用风险信号 |

## 转债评级与信用风险

### 评级分布
| 评级 | 典型特征 | 违约风险 |
|------|---------|---------|
| AAA | 银行/央企/龙头公司 | 极低 |
| AA+ | 优质上市公司 | 很低 |
| AA | 中等资质 | 低 |
| AA- | 较小公司 | 中低 |
| A+ 及以下 | 小市值公司 | 中等 |

### 转债违约先例
中国可转债历史上违约极少，但 2023-2024 部分弱资质转债出现信用风险。关注信号：
- 正股被 ST/*ST → 机构风控不允许持有 → 踩踏抛售
- 正股面临退市 → 转债同步退市（转入退市板块/协议转让）
- 回售/到期偿债能力存疑 → 调查公司账面现金 vs 转债余额

## 转债市场交易特征

### 参与者结构
| 参与者 | 占比 | 交易风格 |
|--------|------|---------|
| 公募基金（债基/混合基） | ~30% | 中长期配置、条款博弈 |
| 年金/保险 | ~20% | 长期持有、偏好高评级 |
| 券商自营 | ~15% | 交易活跃、套利策略 |
| 私募基金 | ~15% | 事件驱动、条款博弈 |
| 个人投资者 | ~20% | 打新、T+0 交易 |

### 转债市场情绪指标
| 指标 | 含义 |
|------|------|
| 全市场平均转股溢价率 | 权益情绪——溢价率↓=市场乐观、溢价率↑=市场谨慎 |
| 全市场平均 YTM | 债市情绪——YTM↑=转债整体便宜（债底支撑强） |
| 破面转债数量 | > 10 只 → 市场极度悲观 |
| 新债上市首日涨幅 | 打新热度——涨停=极热、破发=极冷 |

## 分析流程

1. 获取转债基本信息（转股价、条款、评级、到期日）
2. 获取正股最新价格和波动率
3. 计算核心指标（转股价值、溢价率、纯债价值、YTM、Delta）
4. 判断当前价格主要由股性还是债性驱动
5. 检查下修/强赎/回售条款触发状态和概率
6. 计算盈亏平衡涨幅和下行风险
7. 分析正股基本面（简要）和转债供需
8. 输出可转债分析报告
