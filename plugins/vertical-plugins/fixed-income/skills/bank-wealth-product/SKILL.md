# 银行理财产品分析

> 中国银行理财市场已全面净值化，本文档提供分析框架和关键指标。

## 概述

对银行理财产品进行分析和比较，帮助用户理解净值化转型后的产品特征和风险。

## 中国银行理财市场背景

### 资管新规后的变化
- **净值化转型**：保本型理财退出、全部改为净值型
- **摊余成本法受限**：大部分产品改用市值法估值
- **期限匹配**：非标资产期限须匹配产品期限
- **风险自担**：投资者自担净值波动风险
- **理财产品公司化**：理财子公司独立运营

### 常见产品类型
| 类型 | 风险等级 | 主要投向 | 波动特征 |
|------|---------|---------|---------|
| 现金管理类 | R1 | 货币市场工具 | 极低波动 |
| 纯固收类 | R2 | 存款+短债+同业存单 | 低波动 |
| 固收增强类 | R2-R3 | 债券为主+少量权益/转债 | 中低波动 |
| 混合类 | R3-R4 | 股债混合 | 中等波动 |
| 权益类 | R4-R5 | 股票为主 | 中高波动 |

## 分析维度

### 1. 收益指标
- 近 1/3/6/12 月年化收益率
- 成立以来年化收益率
- 近 7 日年化（现金管理类）
- 万份收益（现金管理类）

### 2. 风险指标
- 净值最大回撤
- 年化波动率
- 负收益天数占比（近一年）
- 跌破净值的频率和持续时间

### 3. 产品要素
- 风险等级（R1-R5）
- 起购金额和追加金额
- 投资期限（T+1 / 固定期限 / 定期开放）
- 申赎规则（开放日、到账日）
- 管理费 + 托管费 + 销售服务费 + 超额业绩报酬

### 4. 投资组合信息
- 大类资产配置比例（存款/债券/非标/权益）
- 前十大持仓（如有）
- 杠杆率
- 组合久期

### 5. 管理人和销售机构
- 管理人（银行理财子公司）
- 管理规模和历史业绩
- 销售费率

## 现金管理类 vs 货币基金对比

| 特征 | 现金管理类理财 | 货币基金 |
|------|--------------|---------|
| 监管 | 国家金融监管总局 | 证监会 |
| T+0 赎回 | 多家银行仍有 | 单只快速赎回限额 1 万 |
| 投资范围 | 略宽于货基 | 严格限定 |
| 起购金额 | 通常 1 万元起 | 1 元起 |

## 分析流程

1. 获取产品说明书或概览信息
2. 确认产品类型和风险等级
3. 分析历史收益和风险指标
4. 分析费用结构（各项费率 + 超额报酬）
5. 如需比较：多产品横向对比表
6. 输出产品分析报告
