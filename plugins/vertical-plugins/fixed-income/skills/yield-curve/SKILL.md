# 收益率曲线分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取利率数据。

## 概述

分析中国国债收益率曲线的形态、变动和隐含信息，帮助理解利率环境和市场预期。

## 中国利率体系

### 政策利率
| 利率 | 含义 | 频率 |
|------|------|------|
| 7 天逆回购利率 | 央行短期政策利率 | 每日 |
| MLF 利率（1 年期） | 中期政策利率 | 每月 15 日 |
| LPR（1Y/5Y+） | 贷款市场报价利率 | 每月 20 日 |
| 存款准备金利率 | 超额准备金利率 | 不定期 |

### 市场利率
| 利率 | 含义 |
|------|------|
| DR007 | 存款类机构 7 天质押式回购利率 |
| R007 | 全市场 7 天质押式回购利率 |
| SHIBOR 3M | 3 个月上海银行间同业拆借利率 |
| 国债收益率（1Y/5Y/10Y/30Y） | 各期限国债到期收益率 |
| 国开债收益率 | 政策性金融债基准 |
| 信用债收益率(AAA/AA+/AA) | 各评级信用债收益率 |

## 收益率曲线形态

| 形态 | 特征 | 含义 |
|------|------|------|
| 正常向上倾斜 | 长端 > 短端 | 经济增长预期正常 |
| 陡峭化 | 长端大幅高于短端 | 宽松货币政策 + 通胀/增长预期 |
| 平坦化 | 长短端利差收窄 | 紧缩政策或经济下行预期 |
| 倒挂 | 短端 > 长端 | 极紧货币或强烈衰退预期 |

### 关键利差
- **10Y-2Y 利差**：最常用的曲线斜率指标
- **10Y-1Y 利差**：中国市场常用（2Y 流动性较差）
- **国债-国开债利差**：隐含税收和流动性溢价
- **信用利差（AAA-国债）**：信用风险定价

## 利率分析框架

### 影响利率的主要因素
| 因素 | 方向 | 传导 |
|------|------|------|
| 经济增长 | 强 → 利率升 | 投资需求 → 资金需求 |
| 通胀 | 高 → 利率升 | 实际利率 = 名义利率 - 通胀 |
| 货币政策 | 松 → 利率降 | 降准/降息 → 资金供给增加 |
| 财政政策 | 宽 → 利率升 | 债券供给增加 → 利率上行 |
| 外部环境 | 美债升 → 中债承压 | 中美利差 → 资本流动 |
| 避险情绪 | 恐慌 → 利率降 | 资金涌入安全资产 |

### 曲线变动分解
- **平行移动**：各期限利率同向同幅度变动（宏观冲击）
- **斜率变动**：曲线变陡或变平（政策预期变化）
- **曲率变动**：中端相对两端的变化（蝴蝶交易）

## 分析流程

1. 获取最新的国债各期限收益率
2. 绘制收益率曲线
3. 计算关键利差（10Y-2Y、10Y-1Y、信用利差）
4. 与历史中枢对比
5. 分析近期变动方向和驱动因素
6. 输出曲线分析报告
