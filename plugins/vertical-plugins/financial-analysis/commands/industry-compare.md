# /cn-finance:industry-compare [行业名称]

## 输入
- `行业名称`（必需）：行业名称，如"白酒"、"光伏"、"半导体"
- 可选参数：`--classification=sw|citics`（行业分类体系，默认 sw 申万）
- 可选参数：`--level=2`（行业分类级别，1-4，默认 2）
- 可选参数：`--metrics=valuation,profit,growth`（比较维度，默认全部）
- 可选参数：`--top=20`（行业内公司数量，默认按市值前20）

## 流程
1. 根据行业分类体系定位目标行业
2. 筛选行业内公司（按市值排序，取前 N 家）
3. 获取各公司的核心财务指标和市场数据
4. 多维度排名比较
5. 计算行业中位数和分布
6. 输出行业比较总表

## 输出
- 行业概览（公司数、总市值、近期涨跌幅）
- 估值比较表（PE/PB/EV-EBITDA + 行业分位）
- 盈利能力排名表（ROE/毛利率/净利率）
- 成长性排名表（收入增速/利润增速）
- 行业集中度分析
