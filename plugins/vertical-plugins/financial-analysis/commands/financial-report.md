# /financial-report [股票代码]

## 输入
- `股票代码`（必需）：6 位数字代码，如 600519
- 可选参数：`--periods=10`（报告期数，默认 10）、`--output=summary|full`（输出详细度）

## 流程
1. 通过用户配置的数据源获取目标公司最近 N 个报告期的三表数据
2. 计算核心财务比率（盈利能力、偿债能力、营运能力、成长能力）
3. 执行杜邦分析拆解 ROE 变动
4. 做同比/环比趋势分析
5. 生成结构化分析报告

## 输出
- 财务比率汇总表
- 杜邦分析拆解
- 同比/环比趋势
- 方向性风险提示

⚠️ 免责声明：以上分析由 AI 工具生成，仅供参考，不构成任何投资建议。投资有风险，决策需谨慎。请咨询持牌专业人士。

## 合规边界
- 不包含具体标的推荐
- 不包含买卖时点建议
- 不包含仓位配置建议
- 输出末尾附带 disclaimer
- 不要求提供证券账户信息
