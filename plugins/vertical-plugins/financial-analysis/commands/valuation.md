# /cn-finance:valuation [股票代码]

## 输入
- `股票代码`（必需）：6 位数字代码
- 可选参数：`--method=dcf|ddm|comps|all`（估值方法，默认 all）
- 可选参数：`--growth=X%`（收入增长率假设）、`--wacc=X%`（折现率假设）

## 流程
1. 获取目标公司和可比公司的财务数据与市场数据
2. 根据用户指定的方法运行估值模型
3. DCF：用户提供或确认 WACC、增长率、终值假设
4. DDM：用户提供或确认分红增长假设
5. 可比公司：自动筛选同行业、相似规模的可比公司
6. 做敏感性分析
7. 输出理论估值区间

## 输出
- 各方法下的理论估值区间
- 敏感性分析表
- 可比公司倍数对照
- 关键假设汇总
