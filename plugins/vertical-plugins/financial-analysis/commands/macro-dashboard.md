# /macro-dashboard

## 输入
- 可选参数：`--indicators=gdp,cpi,ppi,pmi,m2,social-finance`（指定指标，默认全部）
- 可选参数：`--periods=12`（月度数，默认 12 个月）
- 可选参数：`--with-policy`（附带近期货币政策/财政政策动态，默认 true）

## 流程
1. 获取用户指定的宏观指标历史数据
2. 计算趋势、同比、环比
3. 标注近期关键政策变动（降准/降息/专项债等）
4. 生成宏观仪表盘

## 输出
- GDP 季度增速
- CPI/PPI 月度走势
- PMI 月度走势（制造业 + 非制造业）
- M2 和社融月度增速
- LPR 利率走势
- 近期政策动态摘要
