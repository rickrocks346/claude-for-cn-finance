# Excel 模型审计

> 本 skill 为通用工具，与具体金融市场无关。参考 Anthropic 官方 `audit-xls` skill 的核心逻辑。

## 概述

对用户上传的 Excel 金融模型进行自动化审计，检测公式错误、硬编码值、结构问题、平衡性异常。支持 DCF 模型、三表预测模型、LBO 模型、项目评估模型等常见金融模型。

## 审计规则库

### A 级规则：平衡性（Critical — 模型不成立）

| # | 规则 | 检查方法 |
|---|------|---------|
| A1 | 资产负债表平衡 | 对每个预测期：\|总资产 - (总负债 + 所有者权益)\| > 阈值 → CRITICAL |
| A2 | 现金流量表平衡 | 期末现金 = 期初现金 + 现金净增加额 |
| A3 | 三表勾稽：净利润→留存收益 | BS 期末留存收益 = 期初留存收益 + IS 净利润 - 分红 |
| A4 | 三表勾稽：折旧→CAPEX | BS 期末固定资产 = 期初 + CAPEX - 折旧 - 处置 |
| A5 | 三表勾稽：债务→利息 | IS 利息费用 = BS 平均债务 × 利率（偏差 > 10% → WARNING） |
| A6 | 循环引用检测 | A1 单元格引用了 B1，B1 引用了 A1 |
| A7 | 引用完整性 | INDIRECT/OFFSET 等易错函数的使用 |

### B 级规则：公式一致性（Warning — 可能出错）

| # | 规则 | 检查方法 |
|---|------|---------|
| B1 | 横向公式一致性 | 同一行中的公式模式是否一致（比较相邻单元格） |
| B2 | 纵向公式一致性 | 同一列中所有公式类型相同（除了输入行/汇总行） |
| B3 | 求和范围覆盖 | SUM 函数的范围是否覆盖所有数据行 |
| B4 | 跨 Sheet 引用 | 引用了外部工作簿的公式 → 标记为断链风险 |
| B5 | IFERROR 滥用 | IFERROR 包裹公式 → 可能隐藏真正的错误 |
| B6 | 硬编码在公式中 | =B12*0.25 → 数字 0.25 应从假设区引用 |
| B7 | 混合引用检查 | $A1 vs A$1 vs $A$1 是否正确 |

### C 级规则：数据合理性（Suggestion — 优化建议）

| # | 规则 | 检查方法 | 参考区间 |
|---|------|---------|---------|
| C1 | 收入增速合理性 | YoY 收入增速 | -20%~+50%（常规），超出需关注 |
| C2 | 利润率稳定性 | 毛利率/净利率各期偏离度 | 超过 3σ 或突然跳变 → 标记 |
| C3 | CAPEX/折旧比 | CAPEX ÷ 折旧 | 0.8-2.0（维持），<0.5（吃老本），>3（快速扩张） |
| C4 | 营运资本/收入比 | (应收+存货-应付)/收入 | 各行业不同，但大幅波动需解释 |
| C5 | 税率一致性 | 有效税率（所得税/利润总额） | 15%（高新）、25%（普通），跳变→检查 |
| C6 | 终值占比 | TV PV / 总 EV | > 80% → 模型对终值假设过于敏感 |

## Excel 审计实现伪代码

对每个 sheet 执行：
```
打开工作簿 → 遍历每个 sheet:
  1. 识别 "输入区"（手动填假设的区域）:
     - 特征：无公式、颜色/格式不同、有数据验证
  2. 识别 "计算区"（公式驱动的区域）:
     - 特征：包含公式
  3. A 级检查（平衡性）:
     - 搜索 "资产负债表"/"BS"/"Balance" sheet
     - 检查 ASSETS_SUM - (LIAB + EQUITY) 每个预测列
  4. B 级检查（公式一致性）:
     - 对计算区的每行/每列做公式模式聚类
     - 检测偏离模式（离群）的单元格
  5. C 级检查（数据合理性）:
     - 对关键行（收入、成本、利润率等）检查增速和稳定性
  6. 汇总问题分级报告
```

## 模型类型识别

根据 sheet 名称和内容自动判断：
| 模型类型 | 特征 sheet 名 | 关键检测点 |
|---------|-------------|----------|
| DCF 估值 | DCF, Valuation, WACC | FCFF 计算 → WACC → TV → EV |
| 三表预测 | IS, BS, CF, P&L | 三表勾稽 |
| LBO | Sources & Uses, Debt Schedule | 债务摊销 + IRR 计算 |
| 项目评估 | NPV, IRR, Cashflow | 投资 + 运营现金流 + NPV |
| M&A 模型 | Accretion/Dilution | EPS 增厚/稀释分析 |

## 分析流程

1. 用户上传 Excel 文件
2. 自动识别模型类型和结构分区
3. 执行 A 级规则（平衡性，必须全部通过）
4. 执行 B 级规则（公式一致性）
5. 执行 C 级规则（数据合理性）
6. 按严重程度分级输出审计报告
