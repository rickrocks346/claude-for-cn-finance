# Excel 模型审计

> 本 skill 为通用工具，与具体金融市场无关。参考 Anthropic 官方 `audit-xls` skill 的核心逻辑。

## 概述

对用户上传的 Excel 金融模型进行自动化审计，检测公式错误、硬编码值、结构问题、平衡性异常。

## 审计检查清单

### 1. 公式完整性
- 检测所有应包含公式但实际为硬编码的单元格
- 横向/纵向公式一致性检查（同一行/列应有相同公式模式）
- 断链检测（公式引用的外部文件是否可访问）

### 2. 硬编码检测
- 标记公式区域中的硬编码数值
- 区分"合理硬编码"（输入假设区）和"可疑硬编码"（应在公式区但被替换）
- 颜色标记可视化

### 3. 平衡性检查
- 资产负债表：总资产 = 总负债 + 所有者权益
- 现金流量表：期末现金 = 期初现金 + 现金净增加额
- 三表勾稽：净利润 → 经营现金流、折旧摊销 → CAPEX + 折旧

### 4. 公式一致性问题
- 求和范围是否覆盖所有应有行
- 跨 sheet 引用是否正确
- 循环引用检测
- 公式中用到的税率、折现率等参数是否一致

### 5. 数据合理性
- 收入/成本增速是否在合理区间
- 利润率是否在行业范围内
- CAPEX/折旧比例是否合理
- 营运资本占收入比是否稳定

## 审计流程

1. 用户上传 Excel 文件
2. 自动识别模型类型（DCF / 三表预测 / 项目评估等）
3. 按检查清单逐一审计
4. 输出问题列表，按严重程度分级

## 输出格式

```
## Excel 模型审计报告

### 严重问题（Critical）
| # | Sheet | 单元格 | 问题 | 建议 |
|---|-------|--------|------|------|
| 1 | P&L   | C12    | 硬编码替代公式 | 恢复 =B12*增长率 |
| 2 | BS    | D20    | BS不平衡，差额 50,000 | 检查勾稽关系 |

### 警告（Warning）
...

### 建议（Suggestion）
...

### 审计总结
- 检查项: X | 通过: X | 问题: X | 严重: X
```
