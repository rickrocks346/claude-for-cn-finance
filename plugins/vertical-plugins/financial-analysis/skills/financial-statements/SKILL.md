# 财务报表分析

> **数据源**：本 skill 使用用户配置的数据接口（AKShare / Tushare）获取财务报表数据。
> 用户须自行注册数据源账号并配置 API token。Token 存储在用户本地，不会上传或共享。

## 概述

分析中国上市公司财务报表，支持 CAS（中国会计准则）下的三表联动分析、杜邦分析、同比环比分析。

## CAS vs IFRS 差异要点

### 主要差异领域
- 存货计价：CAS 允许先进先出法、加权平均法；IFRS 禁止后进先出法
- 资产减值：CAS 下长期资产减值不可转回（固定资产、无形资产）；IFRS 允许转回
- 政府补助：CAS 下与资产相关的政府补助确认为递延收益
- 合并报表：CAS 下控制权判断强调"权力+可变回报"模型
- 关联方披露：CAS 下国有企业之间交易属于关联方交易

### A股特有科目
- 递延收益 — 非流动负债下的常见科目
- 专项储备 — 安全生产费用等计提，在所有者权益下
- 少数股东权益 — 在利润表中单独列示"归属于少数股东的净利润"

## 三表结构

### 资产负债表
| 资产 | 负债 | 所有者权益 |
|------|------|-----------|
| 流动资产 | 流动负债 | 实收资本/股本 |
| 非流动资产 | 非流动负债 | 资本公积 |
| | | 盈余公积 |
| | | 未分配利润 |

### 利润表
- 营业收入 → 营业成本 → 毛利
- 销售费用 + 管理费用 + 研发费用 + 财务费用
- 营业利润 → 利润总额 → 净利润（含少数股东损益）

### 现金流量表
- 经营活动现金流（间接法为主，部分公司提供直接法）
- 投资活动现金流
- 筹资活动现金流

## 常用财务比率公式

### 盈利能力
| 指标 | 公式 |
|------|------|
| ROE | 净利润 / 平均净资产 |
| ROA | 净利润 / 平均总资产 |
| 毛利率 | (营业收入 - 营业成本) / 营业收入 |
| 净利率 | 净利润 / 营业收入 |

### 偿债能力
| 指标 | 公式 |
|------|------|
| 流动比率 | 流动资产 / 流动负债 |
| 速动比率 | (流动资产 - 存货) / 流动负债 |
| 资产负债率 | 总负债 / 总资产 |
| 利息保障倍数 | EBIT / 利息费用 |

### 营运能力
| 指标 | 公式 |
|------|------|
| 应收账款周转率 | 营业收入 / 平均应收账款 |
| 存货周转率 | 营业成本 / 平均存货 |
| 总资产周转率 | 营业收入 / 平均总资产 |

### 成长能力
- 营业收入同比增长率
- 归母净利润同比增长率
- 经营活动现金流净额同比增长率

## 杜邦分析框架

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/总资产) × (总资产/净资产)
```

### 分析要点
1. 净利率反映产品竞争力和费用控制
2. 总资产周转率反映运营效率
3. 权益乘数反映杠杆水平

## 分析流程

1. 获取最近 5 年（或 10 个报告期）的财务报表数据
2. 做同比环比分析（营业收入、净利润、现金流）
3. 计算核心财务比率
4. 杜邦分析拆解 ROE 变化驱动因素
5. 将分析结果以结构化报告输出
