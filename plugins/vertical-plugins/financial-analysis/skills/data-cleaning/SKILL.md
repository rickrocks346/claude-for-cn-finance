# 金融数据清洗

> 本 skill 为通用工具，与具体金融市场无关。适用于各类金融数据表格的标准化清洗。

## 概述

将用户上传的金融数据表格清洗为标准化的分析可用格式。处理缺失值、重复数据、格式不一致、单位不统一等问题。

## 清洗维度

### 1. 数据完整性
- 缺失值检测与处理策略
  - 时间序列：线性插值或前值填充
  - 截面数据：中位数或均值填充（需标注）
  - 关键字段（股票代码、日期）：缺失则标记整行
- 重复行检测与去重
- 时间跨度连续性检查

### 2. 数据一致性
- 金额单位统一（元 / 万元 / 亿元）
- 日期格式标准化（YYYY-MM-DD）
- 股票代码格式标准化（6位数字）
- 行业分类映射到统一体系

### 3. 数据准确性
- 勾稽关系校验（如资产=负债+权益）
- 同比增长率与原始数据一致性
- 极值检测（超过行业合理范围的标记）
- 符号检查（费用类科目应为负/正一致性）

### 4. 数据可比性
- 合并报表 vs 母公司报表标注
- 会计准则标注（CAS / IFRS / US GAAP）
- 币种统一（如有多币种数据）
- 报告期标注（年报 / 半年报 / 季报）

## 处理流程

1. 扫描数据，生成数据概览（行数、列数、各列类型、缺失率）
2. 与用户确认清洗策略（缺失值填充方式、异常值处理阈值）
3. 执行清洗
4. 输出清洗报告 + 清洗后数据

## 输出格式

```
## 数据清洗报告

### 数据概览
- 原始数据: X 行 × Y 列
- 清洗后: X' 行 × Y' 列

### 清洗操作记录
| 操作 | 影响行数 | 说明 |
|------|---------|------|
| 缺失值填充 | 15 | 应收账款周转率用行业中位数填充 |
| 去重 | 3 | 发现3组完全重复行 |
| 单位统一 | 42 | 统一为"亿元" |

### 异常值标记
| 列 | 值 | 偏离度 | 建议 |
|----|-----|--------|------|
| 毛利率 | -150% | 极端 | 建议人工复核 |
```

## 合规边界
- [ ] 不包含具体标的推荐
- [ ] 不包含买卖时点建议
- [ ] 不包含仓位配置建议
- [ ] 所有分析结果附带免责声明
- [ ] 不要求用户提供证券账户信息
