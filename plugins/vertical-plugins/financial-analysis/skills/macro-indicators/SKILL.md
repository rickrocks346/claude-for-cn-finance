# 宏观经济指标解读

> **数据源**：本 skill 使用用户配置的数据接口获取宏观经济数据。
> 用户须自行注册数据源账号并配置 API token。Token 存储在用户本地，不会上传或共享。

## 概述

对中国宏观经济指标进行结构化整理和解读，帮助用户理解经济周期位置和政策方向。

## 中国核心宏观指标清单

### 经济增长
| 指标 | 发布频率 | 发布机构 | 说明 |
|------|---------|---------|------|
| GDP 及分项 | 季度 | 国家统计局 | 生产法 GDP，含三次产业 |
| 工业增加值 | 月度 | 国家统计局 | 规上工业企业 |
| 固定资产投资 | 月度 | 国家统计局 | 基建、制造业、房地产分项 |
| 社会消费品零售总额 | 月度 | 国家统计局 | 消费端核心指标 |
| 进出口数据 | 月度 | 海关总署 | 进出口金额及增速 |
| PMI（制造业/非制造业）| 月度 | 国家统计局/财新 | 采购经理人指数 |

### 价格指标
| 指标 | 发布频率 | 发布机构 | 说明 |
|------|---------|---------|------|
| CPI | 月度 | 国家统计局 | 消费者物价指数 |
| PPI | 月度 | 国家统计局 | 工业生产者出厂价格 |
| GDP平减指数 | 季度 | 国家统计局 | 综合通胀水平 |

## 数据发布时间表

| 时间 | 指标 |
|------|------|
| 每月 1 日 | 财新制造业 PMI |
| 每月 9-15 日 | 社融、M2、新增贷款 |
| 每月 9-15 日 | CPI、PPI |
| 每月 15 日前后 | 工业增加值、固定资产投资、社零 |
| 每月 20 日 | LPR 报价 |
| 季度结束后 15-20 日 | GDP |

## 常用分析框架

### 美林时钟
- 衰退期 → 复苏期 → 过热期 → 滞胀期
- 基于产出缺口和通胀方向判断当前阶段
- 对应不同资产类别的历史表现

### 三驾马车
- 消费：社零增速、居民收入增速、消费者信心
- 投资：固定资产投资分项（基建/制造业/房地产）
- 净出口：进出口增速差、贸易顺差

### 政策周期
- 货币政策：降准/降息周期、公开市场操作
- 财政政策：赤字率、专项债额度、减税降费
- 产业政策：五年规划、行业专项政策

## 分析流程

1. 获取用户指定的指标及时间范围
2. 计算趋势、同比、环比
3. 与市场预期值对比（如有）
4. 结构性解读（分项拆解）
5. 输出标准化宏观数据报告
