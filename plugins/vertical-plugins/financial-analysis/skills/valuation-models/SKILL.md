## 概述

提供估值模型的计算框架，用户自行填入假设参数。支持绝对值估值（DCF、DDM）和相对估值（可比公司、可比交易）两类方法。

## DCF 模型框架

### 自由现金流预测
```
FCFF = EBIT × (1 - t) + 折旧摊销 - 资本支出 - 营运资本变动
FCFE = FCFF - 利息费用 × (1 - t) + 净借款
```

### WACC 中国市场参数参考
| 参数 | 参考来源 |
|------|---------|
| 无风险利率 | 10年期国债收益率 |
| 股权风险溢价 | 中国 A 股市场通常 5-8% |
| Beta | 从市场数据回归计算 |
| 债务成本 | 公司加权平均借款利率 |
| 税率 | 法定 25%，高新技术企业 15% |

### 终值计算
- Gordon 永续增长模型: TV = FCF_{n+1} / (WACC - g)
- 退出倍数法: TV = EBITDA_n × 退出倍数

### 敏感性分析维度
- WACC 变动 ±1% → 估值变动幅度
- 永续增长率变动 ±0.5% → 估值变动幅度

## DDM 模型框架

```
每股内在价值 = Σ (DPS_t / (1 + r)^t) + DPS_{n+1} / ((r - g) × (1 + r)^n)
```

### 中国 A 股股利特征
- 分红率整体低于成熟市场
- 国企分红率相对稳定
- 银行、公用事业等行业分红率较高
- 部分成长型公司不分红

## 可比公司估值

### A股可比公司选取逻辑
1. 同一申万/中信行业分类（三级或四级）
2. 市值规模相近（±50%）
3. 业务模式相似
4. 上市时间 > 1 年

### 常用估值倍数及行业适用性
| 行业 | 首选倍数 | 次选倍数 | 不适用 |
|------|---------|---------|--------|
| 银行 | PB | PE | EV-EBITDA |
| 消费 | PE | EV-EBITDA | PB |
| 制造业 | PE | EV-EBITDA | PS |
| 互联网/SaaS | PS | EV/Revenue | PE（亏损时）|
| 房地产 | PB(NAV) | PE | EV-EBITDA |
| 保险 | P/EV | PB | PE |

## 分析流程

1. 确认分析目标和方法
2. 获取公司和可比公司财务数据
3. 用户填入关键假设参数（增长率、WACC、终值假设等）
4. 运行模型计算
5. 输出**理论估值区间**（不是目标价）
