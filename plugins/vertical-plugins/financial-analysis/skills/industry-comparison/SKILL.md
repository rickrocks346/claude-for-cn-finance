# 行业比较分析

> **数据源**：本 skill 使用用户配置的数据接口获取行业分类和公司数据。
> 用户须自行注册数据源账号并配置 API token。Token 存储在用户本地，不会上传或共享。

## 概述

基于申万/中信行业分类体系，对中国 A 股行业进行比较分析，包括行业景气度、竞争格局、核心指标对比。

## 中国 A 股行业分类体系

### 申万行业分类
- 一级行业：31 个（2021 版）
- 二级行业：约 130+ 个
- 三级行业：约 340+ 个
- 特点：市场最常用，每 5 年左右大修订

### 中信行业分类
- 一级行业：30 个
- 二级行业：109 个
- 三级行业：285 个
- 特点：与申万高度重叠，细节有差异

## 行业分析框架

### 波特五力
1. 供应商议价能力
2. 买方议价能力
3. 新进入者威胁
4. 替代品威胁
5. 现有竞争者强度

### 行业生命周期
- 导入期 → 成长期 → 成熟期 → 衰退期
- 结合渗透率、收入增速、竞争格局判断

### 行业集中度
- CR3、CR5、CR10（营收占比）
- HHI（赫芬达尔指数）

## 分析流程

1. 确定行业分类（申万/中信 X 级）
2. 筛选行业内可比公司
3. 获取行业关键指标数据
4. 多维度比较（估值、成长性、盈利能力、财务健康）
5. 输出行业比较总表
