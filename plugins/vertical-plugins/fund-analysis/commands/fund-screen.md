# /cn-finance:fund-screen [条件]

## 输入
- `条件`（可选）：筛选条件，如"股票型|近3年收益前20|规模>5亿"
- 可选参数：`--type=stock|mix|bond|money|qdii|etf`（基金类型）
- 可选参数：`--sort=return|sharpe|volatility`（排序依据）
- 可选参数：`--limit=20`（返回条数）

## 流程
1. 解析用户筛选条件
2. 从数据源获取符合条件的基金列表
3. 按指定维度排序
4. 输出基金比较表和综合评分

## 输出
- 筛选条件和结果数量
- 基金比较表（代码、名称、类型、规模、收益、风险、经理）
- 综合排名
