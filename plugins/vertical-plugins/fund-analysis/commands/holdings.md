# /cn-finance:holdings [基金代码]

## 输入
- `基金代码`（必需）：6 位基金代码
- 可选参数：`--history=4`（持仓期数，默认 4 期）
- 可选参数：`--with-peers`（与同类型基金对比持仓）

## 流程
1. 获取基金最新持仓（季报前十大 / 年报中报全持仓）
2. 行业分类汇总（申万一级/二级）
3. 计算持仓集中度和风格指标
4. 与上期对比持仓变动
5. 如指定 `--with-peers`：与同类基金对比持仓差异
6. 输出持仓穿透报告

## 输出
- 前十大重仓股及变动
- 行业配置全景
- 持仓风格九宫格
- 历史持仓变动趋势
