# /manager [基金经理姓名 或 基金代码]

## 输入
- `基金经理姓名` 或 `基金代码`（必需）
- 可选参数：`--period=3y|5y|all`（分析期限，默认 all）、`--compare=peer`（同类经理对比）

## 流程
1. 获取经理管理过的所有基金及任期
2. 计算绝对收益、相对排名、风险调整收益
3. 评估选股能力、择时能力、行业配置能力
4. 分析规模增长对业绩的衰减效应
5. 识别投资风格和风格一致性

## 输出
- 经理履历概览（从业年限、管理规模、历任基金）
- 业绩指标一览（年化收益、夏普、最大回撤、信息比率）
- 能力雷达图（选股/择时/行业/规模管理）
- 风格稳定性评估
