# /style-check [基金代码]

## 输入
- `基金代码`（必需）：6 位基金代码
- 可选参数：`--history=8`（历史持仓期数，默认 8 期）
- 可选参数：`--method=holding|returns|all`（检测方法，默认 all）
  - holdings：基于持仓数据的直接对比
  - returns：基于净值回归的风格分析

## 流程
1. 获取基金合同约定的投资范围和风格定位
2. 获取历史多期持仓数据
3. 逐季计算风格指标（仓位、市值、行业、基准偏离）
4. 绘制风格变动轨迹
5. 判断漂移类型和程度
6. 输出漂移检测报告

## 输出
- 基金声明风格 vs 实际风格对照表
- 风格一致性评分（仓位/市值/行业/基准四维度）
- 历史风格变动轨迹
- 漂移预警信号
