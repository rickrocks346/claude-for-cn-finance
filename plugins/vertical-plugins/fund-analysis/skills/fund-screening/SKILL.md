# 基金筛选与比较

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金数据。

## 概述

基于多维度筛选条件对公募基金进行筛选和横向比较，支持股票型、混合型、债券型、货币型、QDII、ETF 等全品类。

## 中国公募基金分类

| 类型 | 子类型 | 特点 |
|------|--------|------|
| 股票型 | 普通股票型、指数增强型 | 仓位下限 80% |
| 混合型 | 偏股、平衡、偏债、灵活配置 | 仓位灵活，风格分化大 |
| 债券型 | 纯债、一级债、二级债、可转债 | 固收打底+不同增强策略 |
| 货币型 | 货基 | 流动性管理工具 |
| QDII | 股票/债券/混合/REITs | 海外资产配置 |
| ETF | 宽基、行业、主题、跨境、债券 | 场内交易便捷 |
| FOF | 目标日期、目标风险 | 基金中的基金 |

## 筛选维度

### 业绩维度
- 近 1/3/5 年累计收益率
- 年化收益率及波动率
- 夏普比率 / 索提诺比率
- 最大回撤及回撤修复天数
- 年化跟踪误差（指数基金）
- 信息比率

### 风险维度
- 标准差（年化）
- 最大回撤
- VaR（95%/99%）
- 下行标准差
- Beta（相对基准）

### 持仓维度
- 前十大持仓集中度
- 行业集中度（HHI）
- 股票仓位中枢和波动区间
- 重仓股重合度（多只基金比较时）

### 基金经理维度
- 基金经理从业年限
- 管理本基金时长
- 历史管理规模变化
- 跳槽频率（判断稳定性）

### 费用维度
- 管理费 + 托管费率
- 申赎费率（A类 vs C类对比）
- 销售服务费
- 隐性成本（换手率越高交易成本越高）

## 筛选流程

1. 用户指定筛选条件（类型、规模、业绩、风险等）
2. 从数据源获取符合条件的基金列表
3. 多维度打分/排名
4. 输出基金比较表
