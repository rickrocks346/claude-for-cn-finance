# 基金经理历史业绩追踪

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金经理信息和基金净值数据。

## 概述

对基金经理的历史管理业绩、从业经历、管理风格变化进行追踪分析。在中国市场，基金经理个人影响力远大于美国市场，此分析尤为重要。

## 中国市场特殊性

- **基金经理更换频繁**：平均任职年限约 2-3 年，远短于美国
- **一人多基**：同一基金经理管理多只基金，表现可能分化
- **挂名问题**：部分基金名义上是明星经理，实际由实习生/新人管理
- **跳槽影响**：从公募跳槽到私募后业绩普遍下降（投研支持减少）
- **规模是敌人**：管理规模从 10 亿到 100 亿的过程，策略有效性可能大幅衰减

## 分析维度

### 1. 从业履历
- 从业年限（含研究员阶段）
- 历任基金和管理时间
- 历任公司（判断平台 vs 个人能力）
- 研究背景（行业研究员出身 vs 宏观/固收/量化出身）

### 2. 业绩分析
- 历任基金的任职期回报
- 相对基准和同业排名
- 超额收益的稳定性（信息比率、月胜率）
- 最大回撤及回撤区间特征

### 3. 管理能力评估
| 维度 | 评估方法 |
|------|---------|
| 选股能力 | 持仓相对基准的个股超额收益 |
| 择时能力 | 股票仓位变动与市场涨跌的匹配度 |
| 行业配置能力 | 行业超欠配与实际行业表现 |
| 规模管理能力 | 管理规模扩大后业绩衰减程度 |

### 4. 风格演进
- 管理风格是否稳定
- 规模扩大后风格是否变化（被迫大盘化）
- 市场环境适应力（牛/熊/震荡市分别的表现）

### 5. 风险特征
- 各市场的最大回撤
- 回撤修复速度
- 极端事件期间的表现
- 离职期间/过渡期的基金表现

## 分析流程

1. 获取基金经理管理的全部基金列表及任职时间
2. 获取各基金在任职期间的净值数据
3. 计算任职期年化收益、波动、夏普、回撤等指标
4. 计算相对基准和同业的超额收益
5. 评估能力圈和风格特征
6. 输出经理画像报告
