# 基金业绩归因分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金净值和基准数据。

## 概述

对基金的历史业绩进行归因分析，分解收益来源为资产配置、行业配置、个股选择和择时能力等维度。核心目标：回答"基金赚/亏在哪了？Alpha 是否可持续？"

## 归因方法论

### 方法一：Brinson 归因（基于持仓）

#### 单期 Brinson 分解
```
超额收益（相对基准）= 资产配置贡献 + 个股选择贡献 + 交互效应

资产配置贡献 = Σ[(行业i实际权重 - 行业i基准权重) × 行业i基准收益]
个股选择贡献 = Σ[行业i基准权重 × (行业i实际收益 - 行业i基准收益)]
交互效应     = Σ[(行业i实际权重 - 行业i基准权重) × (行业i实际收益 - 行业i基准收益)]
```

#### Brinson 变体对比
| 变体 | 公式特点 | 适用场景 |
|------|---------|---------|
| Brinson-Hood-Beebower (BHB) | 配置贡献用基准权重×(实际权重-基准权重)×基准收益 | 学术标准 |
| Brinson-Fachler (BF) | 配置贡献用(实际权重-基准权重)×(基准行业收益-基准总收益) | 更直观，业内常用 |
| 多期几何链接 | 单期归因结果的几何叠加 | 消除多期叠加的残差 |

#### 归因结果解读
| 结果模式 | 含义 | 能力判断 |
|---------|------|---------|
| 配置贡献持续为正 | 大类资产/行业择时能力强 | 注意区分能力与运气（统计显著性） |
| 个股选择贡献持续为正 | 选股能力强 | 这是最可靠、最可持续的 Alpha 来源 |
| 交互效应大幅为正 | 在正确的时间重仓了正确的行业 | 难以持续，可能是运气 |
| 三项均不稳定 | 业绩驱动因素不明确 | Alpha 可持续性存疑 |

### 方法二：因子归因（Barra 风格 — 基于净值或持仓）

```
基金收益 = α + β_mkt × 市场收益 + β_size × 规模因子 + β_value × 价值因子
         + β_momentum × 动量因子 + β_quality × 质量因子 + β_vol × 波动因子 + ε

其中 α（截距项）代表因子无法解释的超额收益（pure alpha）
```

#### 中国 A 股市场适用的因子
| 因子 | 构造方式（中国版） | 含义 |
|------|------------------|------|
| 市场 (Market) | 沪深 300 全收益 - 1 年期国债利率 | 系统性风险暴露（β 通常在 0.6-1.2） |
| 规模 (Size/SMB) | 中证 500 - 沪深 300（或国证 2000 - 沪深 300） | 小盘溢价 |
| 价值 (Value/HML) | 低 PE/PB 组合 - 高 PE/PB 组合 | 价值因子在 A 股有显著正溢价 |
| 动量 (Momentum) | 过去 12 个月赢家 - 过去 12 个月输家 | A 股动量效应弱于美股，有时反转 |
| 质量 (Quality) | 高 ROE/低杠杆 - 低 ROE/高杠杆 | A 股质量因子溢价明显 |
| 波动 (Low Vol) | 低波动组合 - 高波动组合 | A 股"低波异象"显著 |
| 成长 (Growth) | 高收入/利润增速 - 低增速 | — |
| 分红 (Dividend) | 高股息率 - 低股息率 | A 股投资者结构变化增加此因子重要性 |

### 方法三：Sharpe 风格分析（仅需净值，无需持仓）

```
基金收益 = α + Σ(w_i × 风格指数 i 收益) + ε
约束: Σw_i = 1, w_i ≥ 0 (仅做多)
```

- 用带约束的二次规划/线性回归求解风格暴露 w_i
- R² 越高，风格暴露越明确（R² > 0.8 说明基金是"风格选手"，R² < 0.5 说明"个性选手"）
- 适用于私募基金（不公开持仓）或公募在季报间隔期

## 中国基金归因的特殊考量

### 基准选择问题
| 问题 | 说明 | 处理建议 |
|------|------|---------|
| 基准不具可比性 | 灵活配置型基金基准可能为"一年期定存+3%"，没有实际参考意义 | 改用沪深300或同类基金中位数 |
| 港股暴露 | 通过港股通持有港股，但基准中不含港股因子 | 加入恒生指数作为额外因子 |
| 可转债暴露 | 混合型基金持有可转债，兼具股性和债性 | 单独拆分可转债因子 |
| 打新收益 | A 股网下打新（尤其规模 < 5 亿的基金）可贡献年化 2-5% | 需单独剥离，这不是管理能力 |

### 归因频率选择
| 频率 | 优点 | 缺点 |
|------|------|------|
| 月度 | 数据量大，统计显著 | 忽略月内交易 |
| 季度 | 与持仓披露同步 | 数据量少（3 年仅 12 个点） |
| 日度 | 数据量最大 | 日收益噪音大，短期波动主导 |
| **推荐：月度归因 + 季度持仓交叉验证** | — | — |

### 超额收益分解的特殊项目
| 收益来源 | 特征 | 分析 |
|---------|------|------|
| 选股 Alpha | 持续、稳定、与市场低相关 | 最有价值的 Alpha |
| 打新收益 | 规模 < 10 亿的基金明显 | 规模增大会稀释，不可持续 |
| 大宗交易折价 | 买入折价股票后短期获利 | — |
| 定增折价 | 参与定增，锁定期后获利 | 流动性补偿，非 Alpha |
| 转融通/融券收益 | 出借证券获得利息 | 增厚收益但不可持续 |
| 股指期货基差 | 持有 IC/IM 多头吃贴水 | A 股特有的"制度红利" |

## 归因稳定性分析

### 滚动归因
对每个滚动窗口（如过去 12 个月，每月滚动）做归因，观察归因项的时间序列：
- **选股 Alpha 是否持续为正且稳定？** → 最可靠的信号
- **择时贡献是否"一年好一年坏"？** → 可能是运气
- **因子暴露是否大幅波动？** → 说明风格不稳定

### 统计显著性
对月度超额收益做 t 检验：
```
t = 平均月度超额 / (月度超额标准差 / √n)
t > 2 → 95% 置信度下超额显著（n ≥ 36 即 3 年）
t < 1.5 → 超额不显著，不能排除运气成分
```

### 不同市场环境下的归因
| 市场环境 | 分析重点 |
|---------|---------|
| 牛市 | 选股贡献是否跑赢指数（β 型基金在牛市中 Alpha 容易被掩盖） |
| 熊市 | 择时/风控贡献（是否提前降仓？回撤控制是否超同行？） |
| 震荡市 | 选股 Alpha 的真实体现（最考验选股能力的阶段） |
| 风格极端分化 | 是否因风格暴露赚/亏钱（如 2020 成长强、2022 价值强） |

## 分析流程

1. 确定归因期间和分析频率（推荐月度）
2. 选取合适的业绩基准（如基准不合理则用同类中位数替代）
3. 获取持仓数据，执行 Brinson 归因（首选，最精确）
4. 或仅用净值数据，执行 Sharpe 风格分析 / Barra 因子归因
5. 剥离打新/定增/贴水等制度性收益
6. 滚动归因并评估稳定性
7. 分市场环境（牛/熊/震荡）评估
8. 输出归因分析报告
