# 基金业绩归因分析

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金净值和基准数据。

## 概述

对基金的历史业绩进行归因分析，分解收益来源为资产配置、行业配置、个股选择和择时能力等维度。

## 归因方法论

### Brinson 归因模型
将超额收益（相对基准）分解为：

```
超额收益 = 资产配置贡献 + 个股选择贡献 + 交互效应
```

| 组成部分 | 含义 | 解读 |
|---------|------|------|
| 资产配置贡献 | 大类资产（股/债/现金）权重偏离基准 | 判断大类资产择时能力 |
| 个股选择贡献 | 在同类资产内部选股产生的超额 | 判断选股能力 |
| 交互效应 | 配置和选择的交叉影响 | 通常较小，有时合并处理 |

### 多期 Brinson
- 单期归因可能受市场风格影响
- 多期叠加可以平滑波动
- 按季度归因后汇总，分析各期贡献稳定性

### 因子归因（Barra 风格）
使用多因子模型分解收益：

```
收益 = Alpha + Σ(因子暴露 × 因子收益)
```

| 因子 | 含义 |
|------|------|
| 市场因子 | Beta |
| 规模因子 | 大盘 vs 小盘 |
| 价值因子 | 低估值 vs 高估值 |
| 动量因子 | 趋势跟踪 |
| 质量因子 | 高 ROE/低杠杆 |
| 波动因子 | 低波 vs 高波 |

### Sharpe 风格分析
- 用基金收益率对风格指数做时间序列回归
- 无需持仓明细，只需净值数据
- 适用场景：私募基金（不公开持仓）

## 中国基金归因特殊性

- 基准选择混乱：很多基金的业绩比较基准不具可比性
- 混合型基金仓位灵活，用固定基准归因会有偏差
- 港股/中概持仓：基准中可能不包含港股因子
- 打新收益：A股打新策略带来的无风险增强需单独剥离

## 分析流程

1. 确定归因期间和分析粒度（月/季/年）
2. 选取合适的业绩基准
3. 执行 Brinson 归因（需持仓数据）或 Sharpe 因子归因（仅需净值）
4. 多期汇总，分析归因稳定性
5. 输出归因分析报告
