# 基金风格漂移检测

> **数据源**：本 skill 依赖 financial-analysis 核心层的 AKShare/Tushare connector 获取基金净值、持仓和基准数据。

## 概述

检测公募基金是否偏离其合同约定的投资风格（名称漂移、仓位漂移、市值漂移、行业漂移），帮助用户识别"名不副实"的基金。

## 漂移类型

### 1. 名称/定位漂移
- 基金名称与实际投向不符
- 例：XX"消费"主题基金大量持有新能源
- 例：XX"中小盘"基金重仓沪深300成分股

### 2. 仓位漂移
- 股票仓位长期偏离合同约定区间
- 例：灵活配置型长期满仓运作
- 例：偏股型持续低仓位观望

### 3. 市值风格漂移
- 持仓市值中枢大幅偏离投资目标
- 例：大盘基金持有大量中小盘
- 例：成长基金持仓以低估值价值股为主

### 4. 行业风格漂移
- 行业配置大幅偏离合同方向
- 例：医药主题基金重仓消费/科技
- 例：均衡型基金单行业占比超 40%

### 5. 基准漂移
- 实际投资范围超出了合同约定基准
- 例：A股基金大规模配置港股/US

## 检测方法

### 持仓法（直接，需持仓数据）
- 比较基金合同中的投资范围 vs 实际持仓
- 计算风格一致性得分
- 按季度追踪风格变动轨迹

### 净值回归法（间接，仅需净值）
- Sharpe 风格分析：基金收益对风格指数回归
- 判断风格因子暴露的变化
- 适用于私募和持仓透明的基金

### 基准比较法
- 基金实际走势 vs 合同约定基准
- 如果偏离度持续过大，可能存在风格漂移

## 漂移预警阈值

| 指标 | 预警阈值 | 说明 |
|------|---------|------|
| 主题关联度 | < 60% | 持仓与主题行业的重合度 |
| 仓位偏离度 | > 20% | 实际仓位与合同中值的偏离 |
| 市值风格变动 | > 1个九宫格 | 在风格九宫格中跳跃 |
| 行业集中度 | > 40%单行业 | 均衡型基金单行业占比过高 |

## 分析流程

1. 获取基金合同约定的投资范围和风格定位
2. 获取最近 4-8 个季度的持仓数据
3. 逐季计算风格指标
4. 绘制风格变动轨迹
5. 判断是否存在漂移及漂移程度
6. 输出漂移检测报告
