# 合规红线文档

> 本文档是 claude-for-cn-finance 项目的法律安全底线。
> **所有 skill、command、agent 的编写必须遵守本文档中的规则，无一例外。**

---

## 1. 绝对红线（任何 skill/command 都不得违反）

以下行为在任何场景下都被**绝对禁止**：

| # | 禁止行为 | 具体示例 |
|---|---------|---------|
| 1 | 推荐具体金融产品 | 不得出现"建议买入/卖出 XX 股票/基金/债券"类表述 |
| 2 | 推荐具体买卖时点 | 不得出现"现在是买入时机"/"建议在 X 价位入场"类表述 |
| 3 | 给出明确的仓位配置数字 | 不得出现"建议配置 30% 债券"类表述 |
| 4 | 预测具体价格目标 | 不得出现"目标价 XX 元"/"看到 X 元"类表述 |
| 5 | 模拟或代替持牌投资顾问职能 | 不得以"投资顾问"身份与用户交互 |
| 6 | 收集、存储或转发用户的个人金融数据 | 不得在网络层缓存、日志、中转用户数据 |
| 7 | 接入需要用户证券账户授权的接口 | 不得对接券商交易 API、账户查询接口 |

### 表述规范

以下为**禁止 vs 允许**的表述对照：

| 禁止表述 | 允许替代表述 |
|---------|-------------|
| "建议买入贵州茅台" | "贵州茅台当前 PE 为 28x，处于近五年 30% 分位" |
| "现在是加仓时机" | "当前价格较 60 日均线偏离 -2.3 标准差" |
| "建议配置 40% 权益" | "你的当前组合权益占比 85%，高于你声明的稳健型通常的 50-60% 区间" |
| "目标价 200 元" | "可比公司平均 PE 乘以 EPS 的理论区间为 180-220 元（仅供参考）" |

## 2. 允许的分析行为

以下行为属于**工具性分析**，在附加 disclaimer 的前提下是允许的：

### 财务报表分析
- 三表联动分析（资产负债表、利润表、现金流量表）
- 杜邦分析（ROE 拆解）
- 同比/环比增长率计算
- 财务比率计算（流动比率、速动比率、资产负债率、利息保障倍数等）

### 估值倍数计算
- PE、PB、PS、EV-EBITDA、PEG 等倍数的计算与行业分位展示
- **仅计算，不推荐**："XX 公司 PE 28x = 行业 75 分位" ✓ / "估值合理，建议买入" ✗

### 基金分析
- 基金持仓穿透分析
- 业绩归因（Brinson 归因、因子归因）
- 风格漂移检测
- 费率和跟踪误差计算

### 组合风险分析
- 波动率、最大回撤、夏普比率、索提诺比率、VaR/CVaR
- 相关性矩阵
- 集中度分析（行业、个股、市值风格）
- 压力测试情景模拟

### 风险画像诊断
- 将用户组合的实际风险特征与其声明的风险偏好做对比
- 指出偏离方向（如"组合波动率偏高，与你填写的稳健型偏好不太匹配"）
- **不得给出具体的调仓方案**

### 宏观经济与政策
- 宏观经济数据的结构化整理（GDP、CPI、PMI、社融等）
- 政策文件的关键条款提取
- 利率、汇率趋势图（仅展示历史数据）

### 估值模型框架
- DCF 模型计算框架（用户自行填入假设参数）
- DDM 模型计算框架
- 蒙特卡洛模拟框架（用户自定义分布和参数）

## 3. 每个 skill 和 command 的合规 checklist

**每个 SKILL.md 必须在文件末尾包含以下 section：**

```markdown
## 合规边界
- [ ] 不包含具体标的推荐
- [ ] 不包含买卖时点建议
- [ ] 不包含仓位配置建议
- [ ] 所有分析结果附带"仅供参考，不构成投资建议"disclaimer
- [ ] 不要求用户提供证券账户信息
```

`scripts/check.py` 将对所有 SKILL.md 检查是否包含此合规边界 section。

## 4. Disclaimer 模板

**所有涉及数据输出的 command 必须在输出末尾附加：**

```
⚠️ 免责声明：以上分析由 AI 工具生成，仅供参考，不构成任何投资建议。投资有风险，决策需谨慎。请咨询持牌专业人士。
```

对于实时行情、财务数据类输出，额外附加：

```
📊 数据来源：{用户配置的数据源名称}。数据可能延迟或存在误差，请以官方公告为准。
```

## 5. 相关法规引用

> **注意**：以下条款编号基于公开法律文本。由于 Web Search 工具在当前环境下不可用，条款编号未做实时验证。
> **请在首次使用前由法律专业人士确认最新版本。**

| 法规 | 关键条款 | 与本项目相关性 |
|------|---------|--------------|
| 《中华人民共和国证券法》(2019修订) | 第 160 条 | 证券投资咨询业务须经国务院证券监督管理机构核准，plugin 不得构成"证券投资咨询"行为 |
| 《证券投资顾问业务暂行规定》 | 第 7 条 | 向客户提供投资建议须具备证券投资咨询执业资格，plugin 不得以投资顾问角色交互 |
| 《中华人民共和国个人信息保护法》 | 第 28 条 | 金融账户信息属于敏感个人信息，plugin 不收集、不存储用户个人金融数据 |
| 《生成式人工智能服务管理暂行办法》 | 第 7 条（算法备案）、第 8 条（训练数据合规） | 生成内容须符合法律法规，数据来源合规 |
| 《中华人民共和国数据安全法》 | 第 27 条 | 数据处理者须建立数据安全管理制度，plugin 因不经手数据，责任在用户端 |

### 关键合规要点

1. **不持牌不合规**：本项目及团队不持有中国证券投资咨询牌照，任何构成"投资建议"的行为均违反《证券法》第 160 条
2. **数据在本地**：Plugin 只是分析工具，不收集用户数据，数据安全责任由用户承担
3. **明确免责**：每一条分析输出都必须携带 disclaimer，避免被误读为投资建议

## 6. 数据层合规

### 核心原则

```
用户数据 → 用户本地 → 数据源 API → 用户本地 → Claude 分析
                          ↑
                  Plugin 不在此数据链路上
```

- **Plugin 不存储、不转发、不缓存用户数据**
- 数据源 connector 只是配置模板，用户自行注册和管理 API token
- 用户 token 存储在用户本地的 `.mcp.json` 或环境变量中
- 项目代码中**不得**出现任何真实 token、密钥、账号信息

### .gitignore 要求

以下文件模式必须在 `.gitignore` 中排除：

| 排除模式 | 原因 |
|---------|------|
| `*.local.md` | 可能包含用户自定义的本地配置 |
| `.env` | 环境变量，可能包含数据源 token |
| `.env.*` | 各种环境的环境变量文件 |
| `*.token` | 明确命名的 token 文件 |
| `.mcp.local.json` | 本地 MCP 配置，可能含 token |

### 数据源合规声明

每个使用外部数据源的 skill 必须在文件头部添加：

```markdown
> **数据源**：本 skill 使用 {数据源名称} 数据接口。
> 用户须自行注册 {数据源名称} 账号并配置 API token。
> Token 存储在用户本地，不会上传或共享。
```
